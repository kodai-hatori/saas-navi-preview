Pleskとは？サーバー管理でできること・料金・日本語対応・選び方を解説

開発・インフラ・データ 5,700字
#Plesk #サーバー管理 #海外SaaS

Pleskは、VPSや専用サーバー上の各種サービスをブラウザから管理するコントロールパネルです。Webサイト、メール、DNS、データベースなどを管理しますが、サーバーそのものではありません。

この記事では、Pleskの主な機能、エディション、料金の考え方、日本語対応、入手方法を解説します。導入後に自分で担う管理も取り上げるので、Pleskが必要かどうかを判断する材料にできます。

Pleskとは？管理できるものと向いている人

  • 役割：サーバー管理をGUIにまとめる
  • 管理対象：Web・メール・DNS・DB
  • WordPress：複数サイトをまとめて管理
  • 日本語：UI・公式文書に対応
  • 向く人：複数サイトを管理する担当者

Pleskは、VPSや専用サーバー上の各種サービスをブラウザで操作するための管理画面です。レンタルサーバーやサーバー本体を提供するサービスとは役割が異なります。

Pleskはサーバーを操作する管理画面

サーバーとPleskの関係は、次の4層に分けると理解しやすくなります。

  • OS：Webやメールを動かす土台
  • VPS・専用サーバー：OSを動かす環境
  • Plesk：各サービスを操作する管理画面
  • Webサイト：利用者が公開・運営する内容

公式ストアでPleskのライセンスだけを契約しても、サーバーは付いてきません。一方、ホスティング事業者の付属版では、サーバーとPleskをまとめて契約できる場合があります。

Web担当者・制作会社・ホスティング事業者に向く

Pleskが候補になるのは、管理するサイトや利用者が増え、コマンドラインで個別に設定する負担を減らしたい場面です。

  • Web担当者：自社の複数サイトを管理する
  • 制作会社：顧客ごとに複数サイトを扱う
  • ホスティング事業者：顧客向け環境を提供する

1サイトだけをマネージド型サービスで運営している人は、追加ライセンスが不要なこともあります。Pleskを選ぶ前に、現在の管理方法で困っている作業を洗い出しておくと、導入の必要性を見極める材料になります。

Pleskでできること

Pleskは、サイト公開に必要な設定を一つの管理画面へ集約します。WordPressの更新やサーバー保護も補助しますが、利用できる機能はエディションや追加拡張によって異なります。

Web・メール・DNS・データベースをまとめて管理する

Webサイトの公開には、複数の設定が必要です。ドメインとDNS、ファイルとデータベース、メールをPleskのGUIからまとめて管理できます。

ただし、PleskがWebサーバーやメールサーバーそのものを提供するわけではありません。OS上で動く各サービスの設定を、管理画面から操作できる形にするのがPleskの役割です。

WordPress Toolkitで複数サイトを管理する

WordPress Toolkitでは、WordPressのインストールや更新、複数サイトの管理を一つの画面にまとめられます。管理対象の多い制作会社では、サイトごとに管理画面を行き来する手間を抑えられます。

エディションによって管理できるドメイン数が違うため、契約前にサイト数を数えておきましょう。追加機能を使う場合は、必要な拡張が契約範囲に含まれているかも確認してください。

セキュリティ・バックアップ・監視を補助する

Pleskには、SSL、MFA、更新、バックアップ、監視など、サーバー保護を補助する機能があります。管理項目を画面にまとめられるのが利点です。

ただし、導入しただけで安全性が保証されるわけではありません。更新の方針、バックアップ先、監視で異常を見つけた後の対応は、契約形態と社内の担当範囲に合わせて決めます。

3つのエディションとサーバー種別の選び方

まず、管理するドメイン数と利用者の役割に合うエディションを選びます。次に、導入先に合わせてVPSかDedicatedかを決めます。

Web Admin・Web Pro・Web Hostの違い

3つのエディションでは、管理できるドメイン数と想定する利用者が異なります。

  • Web Admin：10ドメイン。自社サイトの管理向け
  • Web Pro：30ドメイン。制作会社や複数サイト向け
  • Web Host：無制限。顧客向けホスティング向け

Web Adminは小規模な自社運用に、Web Proは複数案件の管理に向きます。Web Hostは、顧客へ環境を提供する事業者向けです。機能差だけでなく、今後増える予定のサイト数も含めて選びます。

VPS版とDedicated版はサーバーに合わせる

エディションとは別に、VPS版とDedicated版があります。これは利用人数ではなく、Pleskを導入するサーバー種別に合わせる区分です。

契約時は「Web ProのVPS版」のように、エディションとサーバー種別を組み合わせます。先に契約中または導入予定のサーバーを確かめ、対応するライセンスを選んでください。

無料プランはないが14日間試せる

Pleskに常設の無料プランはありません。セルフホスト版には、クレジットカード不要の14日間フル機能トライアルがあります。利用できるのは1人・1サーバーにつき1回です。

クラウド事業者がPlesk込みの環境を提供している場合、試用条件はその事業者が定めます。公式のセルフホスト版と同じ条件とは限りません。

Pleskの料金と3つの入手方法

料金は1サーバー単位です。エディション、VPS／Dedicated、月払い／年払いの組み合わせで決まり、契約先によってサポートの範囲も変わります。

  • 公式直販：ライセンスを直接契約する
  • 国内販売店：円建て購入や相談窓口を使う
  • 付属版：サーバーとPleskをまとめて契約する

費用を比べるときは、どこまでを料金に含めるか、次の内訳で条件をそろえます。

  • Pleskのライセンス料金
  • VPSまたは専用サーバーの料金
  • 導入支援や監視などの追加サービス

地域を日本にした公式ストアでは、税別価格が日本円で表示されます。1サーバーあたりの価格は次のとおりです。

  • VPS・Web Admin：月払い2,390円／年払いは月2,190.83円相当
  • VPS・Web Pro：月払い4,080円／年払いは月3,740円相当
  • VPS・Web Host：月払い8,580円／年払いは月7,865円相当
  • Dedicated・Web Admin：月払い2,390円／年払いは月2,190.83円相当
  • Dedicated・Web Pro：月払い4,080円／年払いは月3,740円相当
  • Dedicated・Web Host：月払い9,680円／年払いは月8,873.33円相当

公式ストアでライセンスを直接契約する

公式ストアでは、月払いまたは年払いのリースライセンスを1サーバー単位で契約します。サーバー本体は別に用意し、インストールや初期設定も自分の管理範囲です。

年払いは12か月契約で、月払いより8％低い設定です。契約後に不要となった場合は、自動更新を停止しても支払済み期間の終了まで使えます。

国内販売店から購入する

国内販売店では、日本語で購入相談や導入支援を受けられる場合があります。相談できる範囲、円建て価格、請求方法は販売店ごとに異なります。

販売店の価格には独自の支援が含まれることもあるため、公式直販のライセンス単体価格と単純には比べられません。問い合わせ窓口と解約先も契約前に確かめます。

ホスティング・クラウド付属版を選ぶ

Plesk付きのVPSやクラウド環境なら、サーバーと管理画面を一度に導入できます。事業者によっては初期設定や運用支援も契約範囲に含まれます。

比較するときは、サーバー料金、初期設定、監視、請求元、解約先を分けてください。Plesk込みと書かれていても、保守をすべて任せられるとは限りません。

Pleskの日本語対応と日本からの契約

Plesk Obsidianは、日本語UIと日本語の公式ドキュメントに対応しています。公式ストアでは主要クレジットカードとPayPalを使えます。日本語サポートの窓口は購入経路によって異なります。

管理画面・公式文書・サポートを日本語で使える

管理画面は、ログイン時にインターフェース言語を選ぶか、「Tools & Settings」の「Languages」から日本語へ切り替えられます。利用できる言語数はライセンス条件に依存します。

公式ドキュメントには、Plesk Obsidianの日本語版があります。Plesk直販またはAWS Marketplaceで購入した対象顧客には、日本語の無償直接サポートが付きます。受付は月曜から金曜の10:00〜18:00（日本時間）で、電話には発行済みのチケットIDが必要です。

販売店やPlesk Partnerから購入した場合は、原則として購入先が窓口です。Pleskの直接サポートを使うには、別途サポート契約が必要になる場合があります。

日本円表示でカードとPayPalを使える

日本向けの公式ストアは円表示です。Visa、Mastercard、American Express、JCB、PayPalを利用できます。

注文処理を担うのはCleverbridgeです。請求書は、請求周期ごとに購入時のメールアドレスへ届きます。1ライセンスにつき、サブスクリプションと請求書は一つずつ発行されます。

導入から使い始めるまでの流れ

用意するVPSまたは専用サーバーと契約するライセンスを決めてから、Pleskを導入します。その後、ドメイン、Webサイト、メール、SSL、バックアップを順に設定します。

  1. 対応するVPS・専用サーバーを用意する
  2. エディションとライセンス種別を選ぶ
  3. Pleskを導入し、管理画面へログインする
  4. ドメイン、Web、メール、SSLを設定する
  5. 更新、バックアップ、監視を決める

サーバーとライセンスを用意する

公式直販では、サーバーの準備とPleskの導入を自分で進めます。ホスティング付属版では、事業者が導入済みの環境を提供することもあります。

導入範囲は契約先によって違うため、ライセンスを買う前にサーバーの対応条件を確認してください。トライアルを使う場合も、試用するサーバーを先に用意します。

サイト・メール・SSL・バックアップを設定する

ログイン後は、公開するドメインとWebサイトを登録し、必要ならメールとデータベースを作ります。続いてSSLを設定し、更新とバックアップの方針を決める流れです。

複数サイトを扱う場合は、管理者と顧客の権限も先に分けます。細かな画面名や設定順は契約先の手順を優先してください。

GUIでも管理責任は残る

操作が一つの画面にまとまっても、セキュリティ更新、バックアップ、ファイアウォール、必要ポート、障害対応は管理者の仕事です。

どこまで自社で担うかは、公式直販とマネージド型サービスで大きく異なります。担当者がいない場合は、導入支援や保守を含む契約も比べる必要があります。

cPanelとの違いとPleskが向かないケース

PleskとcPanelは、どちらもサーバー管理に使われるコントロールパネルです。Pleskは対応するLinuxとWindows Serverで動作します。一方、cPanelの公式対応OSはLinux系です。

  • Pleskを検討：複数サイトをGUIで管理したい
  • cPanelも比較：契約先が標準提供している
  • 別サービスを検討：保守を事業者へ任せたい
  • 不要になりやすい：1サイトの既存環境で足りる

cPanelとは4つの軸で比べる

cPanelと比べるときは、まずOSを確認します。Windows Serverで使うならPleskが候補になります。Linuxでは両製品が候補になるため、契約先が標準提供する製品を確かめます。

次に、管理画面の構成、WordPress管理、既存サイトやメールの移行手段を比べます。PleskにはWordPress Toolkitがありますが、利用範囲はエディションや追加拡張によって変わります。

Pleskを選ばなくてもよい人

1サイトだけを運営し、サーバー保守を事業者へ任せている人は、Pleskを追加する利点が小さい場合があります。コマンドによる管理をチーム内で標準化している場合も同様です。

Pleskの価値は、GUIでまとめられる管理作業と、追加ライセンスの費用が見合うかで決まります。保守まで任せたい人は、Plesk単体よりマネージド型サービスを先に比べてください。

まとめ：管理するサイト数と任せたい範囲で選ぶ

複数サイトやWordPressをGUIで管理したいなら、Pleskは候補になります。サーバー保守まで任せたい場合は、マネージド型サービスも比べてください。

Pleskが向いている条件

複数サイトを扱い、WordPressやサーバー設定をブラウザから管理したい人に向きます。日本語UIと公式文書が必要な場合にも候補です。

契約前に確認する条件

契約前には、管理するドメイン数、VPS／Dedicated、購入経路、自分で担う保守範囲を決めます。日本語の直接サポートが必要なら、購入先が窓口になるかどうかも確認してください。
