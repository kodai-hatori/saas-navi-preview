Amazonスクレイピングツールの選び方｜Bright Dataで商品データを取得

Amazonスクレイピングツールは3つの方法から選ぶ

最初に決めたいのは、ツール名よりも取得方法です。欲しいデータと社内の開発体制を照らし合わせ、次の3方式から選びます。

  • 完成データ：収集処理を持たずに使う
  • API：商品やレビューの項目を指定
  • プロキシ：接続地域やIPを細かく制御
  • 主役：3方式をそろえるBright Data
  • 無料枠：対象製品で月5,000クレジット

Bright Dataに登録して無料クレジットを試す →

登録画面では、選んだ製品が月5,000無料クレジットの対象かを確かめられます。

完成済みのデータを受け取るデータセット

データセットなら、自社で収集処理を組まずに、整えられたデータを受け取れます。価格監視や商品一覧の更新を定期的に行いたくても、取得コードの保守に人を割けない場合に向いています。

受け取った後は、分析や社内システムへの取り込みに集中できます。ただし、データセットの価格や更新頻度は一律ではありません。欲しい項目、対象地域、更新間隔を伝え、条件が合っているか確かめます。

必要な項目を取得するAmazon向けスクレイパーAPI

商品情報やレビューなど、取得対象が決まっているならAPIが向いています。価格や在庫にはAmazon Products、評価や本文、著者、日付にはAmazon Reviewsを使います。

対応地域では、Amazon ASINとAmazon PriceがすべてのAmazonドメインを対象としています。Amazon.co.jpの商品URLやASINも入力できますが、出力項目はスクレイパーごとに異なります。

取得処理を自社で組むプロキシ

すでに取得コードがあり、接続地域やIPを細かく制御したい場合はプロキシを使います。ページ構造の変化や失敗時の再試行など、取得処理を自社で管理したい開発チーム向けです。

自由度が高い分、コードの保守は自社で続けます。また、Datacenter、ISP、Residential Proxiesは月5,000無料クレジットの対象外です。APIの無料枠と混同せず、通信量と開発工数を合わせて考えます。

取得したいAmazonデータから方法を選ぶ

同じAmazonデータでも、価格監視とレビュー分析では必要な項目が違います。何に使うかを先に決めると、余分な機能や保守作業を避けられます。

商品名・価格・在庫を追う

商品単位で変化を追うなら、更新頻度を先に決めます。毎回必要な項目が決まっている場合はAmazon向けAPI、定期的にまとまったデータを受け取りたい場合はデータセットが候補です。

  • 欲しい項目：商品名、価格、在庫
  • 向く方式：APIまたはデータセット
  • 先に決める条件：対象商品と更新頻度

価格や在庫は変わるため、一度だけ取得しても継続監視にはなりません。日々の判断に必要な間隔と、取得後に差分を保存する方法まで決めておきます。

ASINや検索結果から商品一覧を作る

市場調査や候補商品の抽出では、キーワードやカテゴリから一覧を作ります。最初から大量取得へ進まず、まず数ページで列の欠損や重複を調べます。その後で範囲を広げると、手戻りを抑えられます。

  • 欲しい項目：ASIN、商品名、カテゴリ
  • 向く方式：APIまたはデータセット
  • 先に決める条件：対象地域、ページ数、出力項目

Amazon.co.jpの商品URLやASINは対象です。検索結果から一覧を作るときは、Amazon Productsのキーワード検索用またはカテゴリURL用スクレイパーを選びます。別地域の商品が同じ列に混在しないようにしてください。

レビュー・評価を分析する

レビュー分析では、本文だけでなく評価や投稿日も必要になります。レビュー向け製品では、ASIN、評価、本文、著者、日付などが取得項目として案内されています。

  • 欲しい項目：評価、本文、著者、日付
  • 向く方式：Amazon向けスクレイパーAPI
  • 先に決める条件：対象ASINと再利用範囲

レビューには個人に結び付く情報や著作物が含まれる場合があります。取得後に社内分析へ使うのか、外部へ表示するのかを分けて扱ってください。

Bright DataでAmazon商品データを取得する手順

初回はAmazon Productsを例に、登録から少量の出力を確認するところまで進めます。管理画面で入力を設定して実行し、結果をダウンロードします。

Bright Dataに登録して無料クレジットを試す →

登録後は、Amazon向けの製品を選び、取得項目を指定して出力結果を確認します。

  1. 登録後、Amazon Scraper APIからAmazon Productsを選ぶ
  2. Amazon.co.jpの商品URLまたはASINを入力する
  3. 少量で実行し、JSONまたはCSVをダウンロードする

アカウントを作り、取得方法を選ぶ

商品名や価格、在庫を取得する場合は、管理画面のAmazon Scraper APIからAmazon Productsを選びます。レビュー分析ならAmazon Reviews、完成済みデータが必要ならAmazon products global datasetが候補です。

月5,000無料クレジットは、Web Scraper APIなどの対象製品で使う共通プールです。プロキシ製品には別のトライアル条件があるため、どの無料枠が適用されるか、表示をよく確かめます。

対象と取得項目を指定する

商品情報を集めるときは、Amazon ProductsにAmazon.co.jpの商品URLまたはASINを入力します。レビューならAmazon Reviewsを選び、商品URLと取得件数を指定します。

商品一覧を作る場合は、キーワード検索用やカテゴリURL用のスクレイパーを使います。目的に合うスクレイパーを選び、最初は対象URLと件数を絞ります。

少量取得してCSV・JSONを確認する

管理画面で入力を設定したら、少量で一度実行します。結果はJSONまたはCSVでダウンロードできるため、ASIN、商品名、価格、通貨、在庫など必要な列を見ます。

欠損や重複があれば、入力したURLとスクレイパーの種類を見直します。必要な列がそろったら、定期実行や保存先への配信に広げます。

無料クレジットと費用は課金単位から考える

費用は、選んだ製品の課金単位で変わります。Amazon Scraper APIは成功レコード、プロキシは通信量、データセットは個別条件で見積もります。

月5,000無料クレジットは対象製品で共用する

新規アカウントには、対象製品で使う月5,000無料クレジットがあります。クレジットカードは不要で、毎月1日に5,000へ戻ります。未使用分の繰り越しはありません。

Web Scraper APIは、1レコードにつき1クレジットを使います。同じ無料枠を対象製品で共有するため、製品ごとに5,000ずつ付くわけではありません。

Datacenter、ISP、Residential Proxiesはこの無料クレジットの対象外です。プロキシには、新規登録時に1回限り$2のトライアルクレジットがあり、有効期間は7日間です。

APIはレコードまたはリクエスト数で考える

APIの予算は「1回に取る成功レコード数×更新回数」で月間の利用量を計算します。商品を毎日追う場合と、月に一度だけ一覧を作る場合では、同じ商品数でも消費量が変わります。

無料クレジットを超えた後は、Amazon Scraper APIの従量課金へ移ります。Pay as you goは、成功した1,000レコードあたり$1.5です。失敗した配信には料金がかかりません。

月額のScaleプランは$499で、384,000レコードを含みます。超過分は1,000レコードあたり$1.3です。少量ならPay as you go、毎月の取得量が増えたらScaleとの総額を比べます。

プロキシは通信量と自社の開発費も含める

Residential Proxiesの従量制は$8／GBで、月額の契約義務はありません。1ドル=158円の概算では約1,264円／GBです。円換算額は為替で変動します。

ただし、プロキシでは取得コードの開発と保守が自社側に残ります。通信量だけで比べると、ページ変更への対応や失敗時の再試行にかかる人件費を見落とします。

日本からはクレジットカード、PayPal、Alipay、Payoneer、Google Pay、Apple Payで支払えます。Wire transferとAmazon Marketplaceは大口アカウント向けです。

カードブランド別の対応にJCBの明記はありません。日本の適格請求書に必要な登録番号も示されていないため、必要な場合は契約前に問い合わせます。サブスクリプション料金は契約後の解約や返金ができません。

Bright Dataに登録して無料クレジットを試す →

Amazon向けに選んだ製品が無料クレジットの対象か、どの単位で課金されるかを登録後に見られます。

Bright Data以外の方法が向くケース

どんな案件にもBright Dataが合うとは限りません。取得件数が少ない場合や公式APIで目的を満たせる場合は、別の方法のほうが手間を抑えられます。

少量を画面操作で取りたいならノーコード型

数件だけを一度取得し、その場で結果を確かめたいならノーコード型が候補です。定期実行や社内システムへの連携が不要なら、APIを組み込む作業を省けます。

目的に合う公式APIがあるなら先に検討する

対象サービスの公式APIで必要な項目がそろうなら、利用条件と再利用範囲を先に比べます。呼び出し上限内で足りる案件では、スクレイピング基盤を別に持たずに済みます。

取得コードを保守できるならプロキシ＋自作

既存コードと保守担当者がいるなら、プロキシと自作コードの組み合わせが候補です。接続地域や再試行を細かく制御できますが、ページ変更時の修正も自社で担います。

IPブロック・利用規約・データの扱いに注意する

技術的に取得できることと、取得したデータを使ってよいことは別の問題です。対象ページと利用目的を決め、アクセス方法と再利用範囲を事前に確かめます。

アクセス頻度とブロック対策を設計する

Amazonのページでは、CAPTCHAやIPブロック、動的描画、ページ構造の変更を想定します。取得間隔と同時接続を抑え、失敗時に無制限で再試行しない設計が必要です。

プロキシやAPIを使っても、すべての取得が成功するとは限りません。失敗したレコードを分けて保存し、後から再実行できるようにしておきます。

Amazonの利用規約とrobots.txtを確認する

対象ページ、取得方法、利用目的によって扱いは変わります。Amazonの利用規約とrobots.txtを読み、一律に合法または違法と決めつけないようにします。

業務利用や外部提供で判断が難しい場合は、法律の専門家へ相談してください。技術担当だけで結論を出さず、利用部門とも範囲を共有します。

レビューや画像の再利用範囲を決める

レビューや商品画像を取得できても、公開や再配布まで自由とは限りません。個人情報、著作権、社内利用か外部提供かを分けて考えます。

通常のResidential Networkへ申し込むにはKYCが必要です。対象は登録済みの法人で、企業ドメインのメール認証と利用目的の提出が求められます。個人や、企業ドメインを持たないフリーランスは通常のKYCへ申請できません。

一方、robots.txtに従って取得するImmediate Residential Accessは、KYCなしで使える場合があります。取得先が該当するかを申し込み前に確認し、KYC申請後は最大48時間の審査を見込みます。

Amazonスクレイピングツールのよくある質問

選ぶときに迷いやすい、日本語対応と無料範囲、Amazon.co.jp、必要な技術知識をまとめます。

Bright Dataは日本語で使える？

日本語の公式サイトと料金ページがあります。ただし、管理画面全体の日本語UI対応範囲は公開情報だけでは分かりません。

日本市場向けの支援は案内されていますが、チャットやメールの応対言語は明記されていません。導入前に、必要な窓口が日本語に対応しているか問い合わせると確実です。

Amazonの商品データを無料で取得できる？

Web Scraper APIなどの対象製品には、月5,000無料クレジットがあります。毎月1日に5,000へ戻り、未使用分は翌月へ繰り越されません。

一方、Datacenter、ISP、Residential Proxiesは対象外です。Amazonデータの取得方法を選んでから、その製品に適用される無料枠を見ます。

Amazon.co.jpのデータも取得できる？

Amazon.co.jpの商品データは取得対象です。なかでもAmazon ASINとAmazon Priceは、すべてのAmazonドメインへの対応を明記しています。

ただし、商品、検索結果、レビューでは使うスクレイパーが異なります。必要なページ種別を選び、少量の結果で商品名や価格、ASINなどの列を見ます。

プログラミング知識は必要？

取得方法によって変わります。完成済みのデータセットなら技術的な負担を抑えられますが、APIでは認証やデータ処理の知識が要ります。プロキシと自作コードは、取得処理の開発と保守まで担う前提です。

コードを書かない担当者が一人で進めるなら、データセットかノーコード型から検討します。開発担当者がいる場合は、必要な制御範囲に応じてAPIやプロキシも候補に加えます。

まとめ：取得したいデータを決めて少量から試す

Amazonスクレイピングツールは、欲しいデータと更新頻度から選びます。方式を先に決め、少量の出力と課金単位を見てから本番件数へ広げるのが安全です。

契約前に確認する5項目

  • 取得項目：商品名、価格、在庫、ASIN、レビュー
  • 更新頻度：単発、毎月、毎日など必要な間隔
  • 取得方式：データセット、API、プロキシ
  • 費用：無料枠とレコード、リクエスト、GB
  • 利用条件：規約、robots.txt、再利用範囲

この5項目を決めておけば、機能の多さだけで選ぶ失敗を減らせます。特に、無料クレジットの対象とプロキシのトライアルは分けて見てください。

Bright Dataが合うか少量で判断する

選べる取得方法は、完成済みデータ、Amazon向けAPI、プロキシの3つです。対象製品なら月5,000無料クレジットがあるため、少量の結果を見て必要項目がそろうかを判断できます。

プロキシ製品は月5,000無料クレジットの対象外です。別のトライアル条件と混同せず、通信量と自社の開発費を含めて比べます。
