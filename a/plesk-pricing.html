Pleskの料金プラン｜エディションの違いから無料体験、日本からの支払いまで

開発・インフラ・データ 4,931字
#Plesk #サーバー管理 #海外SaaS

Pleskはサーバー管理ツールです。Webサイトやメールなどを画面上で管理できます。料金はエディションだけでなく、使うサーバーの種類でも変わります。

この記事では、公式ストアの料金から無料体験、日本からの支払い方法までを順に紹介します。ホスティング会社経由で契約する場合との違いも分かります。

Pleskの料金プランは3種類

Pleskの料金は、エディションとサーバー種別で決まります。まず管理するドメイン数と必要な機能を照合し、VPS版かDedicated版を選びます。

  • Web Admin：月2,390円、10ドメインまで
  • Web Pro：月4,080円、30ドメインまで
  • Web Host：VPS版は月8,580円、Dedicated版は月9,680円
  • 課金単位：1サーバーごと
  • 無料体験：カード不要で14日間

公式サイトで料金を見る →

公式料金ページでは、エディション、サーバー種別、請求周期を切り替えて価格を確認できます。

料金が変わる3つの軸

1つ目は、Web Admin、Web Pro、Web Hostという3つのエディションです。管理できるドメイン数は、それぞれ10、30、無制限です。ドメイン上限で候補を絞ったら、契約前に必要な機能も比べます。

2つ目は、Pleskを入れるサーバーの種類です。仮想サーバー向けのVPS版と、物理専用サーバー向けのDedicated版があります。料金が異なるのはWeb Hostです。

3つ目は、月払いか年払いかです。年払いは12か月契約で、月払いより8％安く設定されています。

国内ホスティング会社から申し込む場合は、Plesk単体の料金とは限りません。サーバー代やサポートを含むことがあるため、公式直販とは条件を分けて比べます。

Pleskの料金一覧（月払い・年払い）

Pleskの直販価格は1サーバー単位です。年払いの表示額は月額相当であり、毎月請求される金額ではありません。

VPS版の料金

VPS版には3つのエディションがあります。金額は日本向け画面の税別価格です。

  • Web Admin：月払い2,390円／月、年払い2,190.83円／月相当、10ドメインまで
  • Web Pro：月払い4,080円／月、年払い3,740円／月相当、30ドメインまで
  • Web Host：月払い8,580円／月、年払い7,865円／月相当、ドメイン数は無制限

小規模なサイト管理なら、Web Adminから検討できます。管理するドメインが10個を超えるなら、上位エディションとの価格差も比べます。

Dedicated版の料金

Dedicated版は、物理専用サーバー向けのライセンスです。AdminとProはVPS版と同額ですが、Hostは価格が上がります。

  • Web Admin：月払い2,390円／月、年払い2,190.83円／月相当、10ドメインまで
  • Web Pro：月払い4,080円／月、年払い3,740円／月相当、30ドメインまで
  • Web Host：月払い9,680円／月、年払い8,873.33円／月相当、ドメイン数は無制限

VPSで使うのにDedicated版を選ぶ必要はありません。契約予定のサーバーがどちらに当たるかを先に確かめると、買い間違いを防げます。

年払いは月払いより8％安い

年払いは12か月契約です。たとえば、VPS版Web Proの「3,740円／月相当」は、1か月ずつ3,740円を払う意味ではありません。年間の利用料を月数で割った表示です。

短期間だけ使うなら月払い、1年以上続ける前提なら年払いが候補になります。更新時期まで含めて予算を組むなら、月額相当ではなく、実際の請求周期に合わせて考えます。

月払いと年払いを切り替えると、同じエディションの価格差を見比べられます。

Web Admin・Web Pro・Web Hostの選び方

管理ドメイン数は、エディションの一次候補を絞る目安です。上限だけで契約を決めず、必要な機能が候補のエディションに含まれるかも料金ページで照合します。

Web Adminは10ドメインまで

追加予定を含めて10ドメイン以内なら、Web Adminが候補に入ります。必要な機能がそろうかを確かめ、上限に近い場合はWeb Proとの価格差も比べます。

Web Proは30ドメインまで

Web Proは、10ドメインを超えても30ドメイン以内に収まる場合の候補です。今後30を超える見込みと、必要な機能の有無を確かめてから決めます。

Web Hostはドメイン数が無制限

30ドメインを超えるなら、Web Hostが候補です。無制限になるのは管理ドメイン数で、サーバーの容量や処理性能は含みません。VPS版とDedicated版の価格差も比べて選びます。

Pleskに無料プランはないが14日間試せる

現行のPleskには、期限なく使える無料プランがありません。一方、セルフホスト版には14日間のフル機能トライアルがあります。

  • 無料プラン：なし
  • 無料体験：14日間
  • 登録条件：クレジットカード不要
  • 利用回数：1人／1サーバーにつき1回

無料プランと無料SSLは別の話

「Plesk 無料」で情報を探すと、無料SSLの設定方法も見つかります。ここで無料なのはSSL証明書であり、Plesk本体のライセンスが無料になるわけではありません。

費用をかけずにPlesk本体を試す方法は、14日間のトライアルです。無料SSLとPlesk本体の無料体験は、同じ「無料」でも内容が異なります。

無料体験の条件と注意点

セルフホスト版の無料体験は、クレジットカードを登録せずに始められます。利用できるのは1人につき1回、かつ1台のサーバーにつき1回です。

クラウド事業者がPleskを組み込んだサーバーを提供している場合、試用条件は各社で異なります。Plesk公式の14日間という条件を、そのまま他社契約へ当てはめないようにしてください。

公式料金ページから、無料体験の対象と開始条件を確認できます。

公式直販とホスティング付属では支払う総額が変わる

表示されている価格は、Pleskライセンス1台分です。サーバー本体や追加サービスの費用は含まれません。

公式ストアはPleskライセンスを1サーバー単位で買う

購入できるのは、月払いまたは年払いのリースライセンスです。ライセンスは1台のサーバーごとに必要となります。

支払総額を出すときは、次の費用を分けて考えます。

  • Pleskのライセンス
  • VPSまたは専用サーバー本体
  • 必要に応じて追加する有料機能
  • 外部へ頼む場合の導入・保守支援

Pleskの表示価格だけでサーバーを動かせるわけではありません。すでにサーバーを契約しているなら、その環境がVPS版とDedicated版のどちらに当たるかも確認します。

ホスティング付属版はサーバー代と契約条件を見る

国内のホスティング会社では、Pleskがサーバープランに含まれる場合と、追加オプションになる場合があります。比較するときは、Pleskだけの金額を抜き出すと、実際の支払総額が分かりません。

サーバー代、初期費用、Pleskライセンス、サポートの範囲を同じ条件で並べます。解約は契約したホスティング会社で手続きする場合があります。

日本からの支払い・請求書・税表示

日本から選べる支払方法は、主要クレジットカードとPayPalです。料金画面は円建ての税別表示で、Cleverbridgeが決済後の請求書を発行します。

  • 表示通貨：日本円
  • 価格表示：税別
  • 支払手段：主要カード、PayPal
  • 請求書：決済後、請求周期ごとにメール送付
  • JCB：公式情報では未確認

本記事の料金欄は、日本向け画面の円表示をそのまま記載しています。

主要クレジットカードとPayPalで支払える

日本から公式ストアで購入する場合、主要クレジットカードまたはPayPalを選べます。公式情報では対応ブランドを個別に確認できないため、JCBが使えるとは断定できません。

表示価格は税別です。居住国によってVATなどが加算される場合があります。日本の税務処理や控除の扱いは、税理士に確認してください。

請求書はメールまたは注文情報ページから受け取る

請求書は、月または年の請求周期ごとに購入時のメールアドレスへ届きます。見つからない場合は、Cleverbridgeの注文情報再送ページから請求書リンクを取り寄せられます。

この請求書は決済後の記録です。銀行振込などの請求書払いを示すものではありません。

複数のライセンスを買うと、1ライセンスごとに別のサブスクリプションと請求書が作られます。経理処理では、ライセンス数と請求書の枚数を照合してください。

購入前に、表示通貨、請求周期、税の注記を料金ページで確認できます。

解約・ダウングレード・返金の条件

直販契約は、自動更新を停止して解約します。解約後も支払済み期間までは使えますが、解約しただけでは返金されません。

自動更新は管理画面かメールから停止する

自動更新は初期設定で有効です。停止する場合は、Plesk 360またはWebPros Dashboardの「Unsubscribe」を使います。

Cleverbridgeから届くメール内の「Cancel your subscription」からも手続きできます。手続き後は契約状態を開き、次回更新の前に停止できたかを確かめます。

解約後も支払済み期間までは使える

自動更新を止めても、ライセンスが即時に使えなくなるわけではありません。すでに支払った期間の終了までは有効です。

新規購入分は、購入後14日以内なら返金を申請できます。ただし、解約そのものに返金効果はありません。返金を求める場合は、解約とは別に申請が必要です。

ダウングレードと第三者購入は契約先の条件を確認する

公式直販では、エディション間のアップグレードとダウングレードを随時行えます。

販売店、クラウド事業者、ホスティング会社から購入したライセンスには、各社の解約・返金条件が適用されます。Plesk公式ストアの条件とは分けて扱います。

Pleskの料金でよくある質問

Pleskは1サーバー単位で契約します。エディションの機能とドメイン上限、サーバー種別を照合してライセンスを選びます。

Pleskの料金はユーザー数課金ですか？

料金はユーザー数ではなく、1サーバー単位です。エディションごとに管理ドメイン数の上限が異なります。

Pleskをずっと無料で使えますか？

常設の無料プランはありません。セルフホスト版は、クレジットカードなしで14日間試せます。無料SSLは別の機能です。

Pleskは日本語で使えますか？

Plesk Obsidianは日本語UIに対応しています。ログイン時の言語選択、または「Tools & Settings」から日本語へ切り替えられます。

日本語の公式ドキュメントもあり、電話・メールの日本語サポートは月〜金の10時〜18時に提供されています。電話には発行済みのチケットIDが必要です。

まとめ

Pleskは、管理ドメイン数からエディションの候補を絞り、必要な機能を満たすかを照合します。続いてサーバー種別を合わせ、月払いと年払いを比べる流れです。

  • エディション：ドメイン上限と必要機能
  • サーバー種別：VPS／Dedicated
  • 契約経路：公式直販／ホスティング付属
  • 請求周期：月払い／12か月の年払い

公式直販の表示額はPleskライセンスの料金です。ホスティング付属版と比べるなら、サーバー代、初期費用、サポート、解約条件まで同じ範囲にそろえると、実際の差が分かります。
