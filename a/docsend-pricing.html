DocSendの料金プラン｜無料トライアルと機能差、日本から申し込む前の確認点

契約・書類・PDF 4,897字
#DocSend #資料共有 #電子署名

DocSendは、送った資料の閲覧状況を追跡できる共有サービスです。料金は利用人数と、電子署名やデータルームの要否で変わります。

公開中の有料3プランについて、料金と機能の違いを整理しました。無料トライアルの条件と、日本から契約する前の確認点も分かります。

DocSendの料金プランは3種類

DocSendで公開されている有料プランは3種類です。無料体験後に移行する制限付きプランは、有料プランとは分けて考えます。

  • Standard：月43ドル／1ユーザー
  • Advanced：月250ドル／3人込み
  • Advanced Data Rooms：月300ドル／3人込み
  • 無料体験：14日間／カード不要
  • 終了後：無料の制限付きプラン
  • 年払い：最大40%割引

料金ページで現行3プランを比べ、無料トライアルへ進めます。

月払いの料金と年払いの割引をプラン別に見る

Standardは1ユーザーごとの料金です。Advanced以上の表示額には3ユーザー分が含まれるため、利用人数も合わせて比べます。

年払いを選ぶと、1か月あたりの換算額はStandardが30ドル、Advancedが150ドル、Advanced Data Roomsが180ドルです。ただし、年額を12回に分けて支払う仕組みではありません。

Standardは複数ファイル共有と電子署名を増やしたい場合

  • 月払い：43ドル／ユーザー／月
  • 年払い：30ドル／ユーザー／月換算
  • 課金単位：1ユーザー
  • 主な機能：複数ファイル共有、無制限の電子署名

Standardは、複数の資料をまとめて送りたい人向けの公開最安プランです。電子署名も件数の上限がなく、資料共有と署名を一つのサービスにまとめられます。

利用者が増えると、料金も人数に応じて上がります。3人で使う場合は、Advancedの3ユーザー込み料金と総額を比べると差が分かります。

Advancedは3人でSpacesを使いたい場合

  • 月払い：250ドル／月
  • 年払い：150ドル／月換算
  • 含まれるユーザー：3人
  • 主な機能：Spaces、高度なセキュリティ

Advancedは3人分を含む定額表示です。複数の資料をSpacesにまとめ、チーム内で共有したい場合に向いています。

4人以上で使う場合はライセンスを追加できますが、追加席の単価は公開されていません。総額は、請求画面か営業窓口で見積もりを取ります。

Advanced Data Roomsは高度な管理が必要な場合

  • 月払い：300ドル／月
  • 年払い：180ドル／月換算
  • 含まれるユーザー：3人
  • 主な機能：監査ログ、グループ権限、インデックス自動作成

Advanced Data Roomsは、資金調達やM&Aなどで機密資料を共有するチーム向けです。誰が何を閲覧したかを監査ログで追い、閲覧範囲をグループ単位で分けられます。

Advancedとの差額は月払いで50ドル、年払い時の月額換算で30ドルです。社外の関係者ごとに権限を分ける必要があるかどうかで選びます。

料金ページの請求周期を切り替えると、月払いと年払い時の月額換算をその場で見比べられます。

無料プランはなく、データルームを14日間試せる

DocSendに通常のFreeプランはありません。新規アカウントはAdvanced Data Roomsの14日間無料トライアルへ登録され、クレジットカードなしで始められます。

  • 期間：14日間
  • カード登録：不要
  • 対象：Advanced Data Rooms
  • 文書：最大500件
  • チーム招待：最大20人
  • 電子署名：最大50件

14日が過ぎると、有料機能を試せる期間は終了します。ただし、カードを登録していなければ自動課金はありません。

トライアルで確認する機能を先に決める

体験期間中は、契約後に使う場面を想定して次の操作を試します。

  • Spacesに資料をまとめる
  • 閲覧権限を設定する
  • チームで資料を共有する
  • 受け手側の表示を確かめる

トライアルでは、権限設定を重点的に確かめます。Advancedで足りるのか、監査ログやグループ権限を備えたAdvanced Data Roomsが必要なのかを比べてください。

トライアル終了後の状態は公式条件を確認する

カードを登録しないまま14日間が終わると、無料の制限付きトライアルプランへ自動移行します。プレミアム機能で作ったリンクは無効になるため、社外へ共有中の資料があれば終了日前に対応してください。

トライアル中に別プランへアップグレードすると、その時点で課金が始まります。自動課金を避けたい場合は、カードを登録せずに試します。

カードを登録せず、Advanced Data Roomsの試用を始められます。

必要な機能から選ぶとプランを絞りやすい

公開プランは、複数ファイル共有と電子署名、Spaces、データルームの管理機能という順に範囲が広がります。必要な機能を初めて含むプランが、選択の基準です。

複数ファイル共有と電子署名ならStandardを見る

Standardは複数ファイル共有に対応し、電子署名は無制限です。提案資料と契約書などを一緒に送りたい場合に向きます。

1ユーザーごとの課金なので、3人で利用するならAdvancedも比較対象です。Standardを同じ人数で使う総額とAdvancedの定額を並べて判断します。

Spacesと高度なセキュリティは上位プランで比べる

資料をSpacesにまとめるなら、Advanced以上が候補です。どちらも3ユーザー分を含み、高度なセキュリティを備えています。

監査ログ、グループ権限、インデックス自動作成が必要ならAdvanced Data Roomsを選びます。社外へ共有しても関係者別の権限管理までは要らない場合は、Advancedが候補です。

日本から申し込む前に支払いと請求条件を確認する

公式直契約の料金表示はUSDです。主要クレジットカードに対応していますが、日本発行カードとJCBの利用可否は公開情報だけでは判断できません。

公式直契約の表示通貨はUSD

料金ページは米ドル表示です。日本円の請求額は、決済時の為替とカード会社の手数料で変わります。

社内申請では、ドル建ての契約額を基準にします。円換算額だけで予算を確定すると、決済日の為替によって差が生じる可能性があります。

カードと請求書は契約画面で最終確認する

公式ヘルプでは、Visa、Mastercard、American Expressを含む主要クレジットカードに対応しています。一方、日本発行カードとJCBに関する案内はありません。

DocSendのセルフサービス契約で請求書を取得する手順も公開されていません。請求書が必要な法人は、申込前に契約画面か問い合わせ窓口で発行できるか確かめます。

税の表示と経理処理は契約条件を見たうえで、必要に応じて税理士へ確認してください。

日本語ヘルプから問い合わせられる

DocSendには日本語のヘルプ画面と問い合わせフォームがあります。ただし、フォームの一部は英語で、担当者からの回答が日本語になる保証も示されていません。

日本語UIの対応範囲も公開情報では判断できません。英語画面が業務の妨げになる場合は、無料トライアル中に管理画面を確認します。

料金ページから契約画面へ進むと、請求通貨と利用できる決済手段を申込前に確かめられます。

電子署名を重視するならPandaDocとも比べる

DocSendは資料の閲覧追跡とデータルームに強みがあります。提案書の作成と電子署名を主に使うなら、PandaDocも比較候補に入ります。

  • DocSend：閲覧追跡とSpacesに対応
  • DocSend：14日間の無料トライアルあり
  • PandaDoc：Free eSignは月額0ドル
  • PandaDoc：提案書と電子署名が中心

閲覧追跡か、提案書と電子署名かで選ぶ

送った資料の閲覧状況を追い、データルームまで使うならDocSendが軸です。一方、PandaDocには年間60文書まで使える無料の電子署名枠があります。

PandaDocのFree eSignは、1文書あたりの受信者が2人、テンプレートは5件です。ただし、管理画面と受信者画面の公式対応言語に日本語は含まれません。日本語サポートも明記されておらず、設定や問い合わせには英語を使う前提です。

資料の閲覧状況を営業活動に生かすならDocSend、署名文書を無料枠から作るならPandaDocという分け方です。

解約は更新前に行い、期間途中の返金は原則ない

セルフサービス契約は、Admin Consoleから更新前に解約できます。手続きが反映されるのは、現在の契約期間の末日です。

解約は現契約期間の末日に反映される

DocSendの契約は自動更新です。次回分を止めるには、更新日より前に解約手続きを済ませます。

手続きの直後に有料機能が止まるわけではありません。契約期間の末日に無料の制限付きトライアルプランへ移行します。

未使用期間の返金を前提にしない

支払済みの料金は、法令などで返金が認められる場合を除き、戻りません。途中で利用をやめても、未使用期間分の返金はないものとして契約を検討します。

年払いは最大40%割引になる一方、契約期間が長くなります。必要な利用期間と更新日も合わせて検討します。

DocSendの料金でよくある質問

契約直前に迷いやすい、無料枠と課金単位、支払いについて答えます。

DocSendにずっと使える無料プランはある？

通常のFreeプランはありません。14日間のAdvanced Data Roomsトライアルが終わると、カード未登録なら無料の制限付きトライアルプランへ移行します。

プレミアム機能で作ったリンクは無効になり、有料プランと同じ機能は残りません。

表示料金は1人分？

Standardは1ユーザー単位です。AdvancedとAdvanced Data Roomsは、3ユーザー分を含む月額で表示されます。

3人で契約する場合は、Standardの3人分と上位プランの表示額を比べます。

日本からカードで支払える？

Visa、Mastercard、American Expressを含む主要カードに対応しています。ただし、日本発行カードとJCBの利用可否は公開情報に記載されていません。

利用予定のカードが契約画面に表示されるか、申込前に確認してください。

年払いはいくら安くなる？

年払い時の月額換算は、Standardが30ドル、Advancedが150ドル、Advanced Data Roomsが180ドルです。月払いと比べると、割引率は最大40%になります。

年払いは年間契約です。月額換算だけでなく、契約期間全体の支払額を見て選びます。

まとめ：人数と必要機能を決めてからプランを選ぶ

DocSendの公開有料プランは3つです。1人単位のStandardと、3ユーザー込みの上位2プランでは課金単位が異なります。

  • 複数ファイルと電子署名：Standard
  • Spacesと高度なセキュリティ：Advanced
  • 監査ログとグループ権限：Advanced Data Rooms
  • 無料体験：14日間、カード登録不要
  • 請求：USD、主要カードに対応
  • 解約：契約期間末に制限付きプランへ移行

まず利用人数を決め、次に必要な管理機能を選びます。14日間のトライアルで権限設定と受け手側の表示を試しておけば、契約後の想定違いを減らせます。
