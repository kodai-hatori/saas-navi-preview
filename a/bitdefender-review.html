Bitdefenderの評判は？メリット・デメリット、安全性と向いている人を解説

セキュリティ・ストレージ 6,111字
#Bitdefender #セキュリティソフト #海外SaaS

Bitdefender（ビットディフェンダー）は、Windows・Mac・スマホを守る海外製セキュリティソフトです。マルウェアや危険なWebサイトへの対策に使います。この記事では、評判の傾向、日本語対応、安全性、料金の注意点を紹介します。

Bitdefenderの良い評判・メリット

日本語メニューから製品を比較でき、ダウンロードやサポートのページにも進めます。

防御性能の高さを評価する声が目立ちます。危険なサイトへの対策と、複数端末をまとめて管理できる点も好評。 Antivirus FreeはWindows向けの無料製品です。一方、Total Securityは有料製品。口コミは分けて読んでください。

防御性能とWeb保護を評価する声がある

無料版でも検出力に満足しているという投稿は、国内のフリーソフトレビューサイトで目立ちます。国内のセキュリティ専門メディアも、AV-TESTやAV-Comparativesの結果を根拠に、防御率を高く評価しています。

専門メディアのレビューでは、不審なWebサイトを開く前に止める機能も長所に挙がっています。ただし、レビューには無料版と有料版の話が混ざっているため、客観的な根拠には後述する第三者試験を使います。

複数OS・複数端末をまとめて管理できる

家族の端末をまとめて守れる点や、導入の手軽さを評価する声もあり、公式情報とも一致します。

  • 公開レビューの声：1つの契約で家族のPCとスマホを守れ、インストールも簡単だった
  • 公式情報：契約内容と端末は、Webの管理画面Bitdefender Centralで一元管理できる

標準のVPNも含まれますが、1台あたり1日200MBまでです。動画をVPN経由で長時間見るには、容量が足りません。

無料版とカード不要の体験版から始められる

お金をかける前に試せる点も評価されています。選択肢は、利用期限のないWindows専用のAntivirus Freeと、Total Securityの30日間体験。後者もカード登録は不要で、期間が終わると失効します。自動で有料契約に切り替わる心配はありません。

Bitdefenderの悪い評判・デメリット

目立つのは、動作の重さと通知・広告への不満。誤検知や他ソフトとの相性のほか、サポート対応を問題にする声もあります。 動作の重さは評価が分かれるため、端末や製品の違いも踏まえて読みましょう。

「軽い」と「重い」の評価は端末や処理で分かれる

同じレビューサイトの中でも、「ほかのソフトより軽い」という声と「メモリ消費が大きく重い」という声が並んでいます。導入直後のフルスキャンに時間がかかったという投稿も見られます。

重いという投稿で多いのは、初回スキャン中の話やメモリ消費の話。端末の性能や製品の世代も異なるため、単純には比べられません。古いPCを使うなら、初回スキャン後も作業が遅くならないか、体験版で試してみてください。

通知や誤検知のほか、他ソフトとの競合を指摘する声もある

動作以外では、次の4点が不満として挙がっています。

  • 通知・広告：無料版で有料版への案内や通知が表示される、購入後に広告メールが届く
  • 誤検知：問題のないファイルやソフトがブロックされ、例外設定が必要になったという投稿がある
  • 他ソフトとの競合：別のセキュリティソフトと同時に入れて、動作が不安定になったという投稿がある
  • サポート：問い合わせ対応や、更新時の請求に関する不満が見られる

常駐型のセキュリティソフトを2本同時に動かすと、競合が起こりやすくなります。乗り換えの基本は、既存のソフトを削除してからBitdefenderを入れること。仕事で使うソフトが誤検知された場合に、除外設定で使い続けられるかも体験版で試しておきましょう。

古い無料版や旧UIの口コミは現行製品と分けて読む

検索上位のレビューには、数年前の無料版や、画面構成が今とは違う時期の投稿も含まれます。円価格を載せた古い記事もあり、現在の条件とは一致しません。

製品名にも注意が必要です。現在の米国公式サイトに並ぶ製品系統は4つです。

  • Antivirus Plus
  • Total Security
  • Premium Security
  • Ultimate Security

古い記事には、いまの個人向けラインナップに見当たらないInternet Securityなどの名前も出てきます。口コミを読むときは、投稿時期と対象製品を照らし合わせてください。

Bitdefenderは安全？危険性を判断する3つの軸

「評判が良いから安全」とは限りません。判断材料は、第三者試験と製品が求める権限。守れる範囲に加え、契約とアカウントの管理も見ておきましょう。

第三者試験は最新の一次情報を参照する

Bitdefenderは公式の製品ページで、過去10年分の独立系試験のスコアを防御性能の根拠に挙げています。国内外のレビューでよく引用されるAV-TESTやAV-Comparativesも、独立した評価機関。結果は回ごとに更新されます。古い記事の点数や順位ではなく、評価機関が公表した最新の結果を見てください。

必要な権限と保護機能を製品別に確認する

Total SecurityやAntivirus Plusは、端末内のファイルを監視します。VPNで通信も保護するため、権限は端末の深い部分まで及びます。

いずれも保護に必要な権限であり、範囲が広いだけで危険とはいえません。

製品ごとに、守れる範囲は異なります。Antivirus Freeの対象は、Windowsの基本保護まで。Mac・スマートフォン・VPNまで含めるなら、Antivirus PlusやTotal Securityなどの有料製品が対象です。偽のインストーラーを避けるため、ダウンロードは公式サイトから行ってください。

自動更新とアカウント管理を安全性とは分けて考える

海外のレビューサイトには更新時の請求に関する不満も見られますが、これは防御性能ではなく契約管理の問題です。有料版の契約内容や更新日は、Bitdefender Centralで管理。購入したら、自動更新の状態と次回更新日をメモしておくと、予期しない請求を防げます。

日本語UIと日本語サポートは同じではない

Bitdefender CentralとAndroid版Mobile Securityは日本語に対応しています。iOS版のMobile SecurityとBitdefender VPNも、日本語表示に対応。ほかのOSや有人サポートには、公式な日本語対応の記載がありません。

Centralと一部アプリでは日本語を確認できる

契約と端末は、Bitdefender Centralで管理します。言語一覧でJapaneseを選ぶと、画面が日本語に切り替わります。Android版Mobile Securityは、公式FAQにJapanese対応との記載。一方、iOS版Mobile SecurityとiOS版VPNは、日本向けApp Storeの言語欄に日本語の記載があります。

Windows・Mac・VPNは対応範囲を一括りにしない

現行ヘルプには、Windows製品の表示言語を変える手順があります。ただし、Japaneseを選べるかは書かれていません。

日本語版ユーザーガイドは2021年版で、現行画面と同じとは限りません。

Mac版とiOS以外のVPNも、公式情報に日本語対応の記載がありません。Windowsの日本語画面が必須なら、体験版を入れて言語一覧にJapaneseがあるか見ておきましょう。

公式有人サポートに日本語対応の記載はない

Bitdefenderには公式のサポート窓口と24時間対応のチャットがあります。ただし、日本語対応の明記はありません。

画面やマニュアルが日本語でも、担当者とのやり取りは英語になる可能性があります。更新や返金を日本語で相談したい人は、日本語窓口がある製品とも比べてください。

無料版・料金・支払い・解約で注意すること

恒久無料のAntivirus Freeと、Total Securityの30日間無料体験は別物です。有料契約でまず見るのは、初年度と更新時の価格。自動更新の止め方と返金条件も、購入前に押さえておきましょう。

Antivirus FreeとTotal Securityの無料体験は別物

無料で使う方法と有料版の違いは、次のとおりです。

  • Antivirus Free：Windows専用の基本保護。隠れた費用や利用期限はない
  • Total Securityの無料体験：製品版と同じ機能を30日間使える。カード登録は不要で、期間終了後に失効する
  • 有料版：Antivirus Plus（1台・3台）、Total Security（5台・25台）などから、守る台数で選ぶ

Total Securityと同じ内容をずっと無料で使えるプランは、公式のラインナップに見当たりません。

初年度価格と更新条件は分けて考える

米国公式の初年度価格は、Total Security Individual（5台）が年額$59.99です。1ドル=158円で換算すると、約9,500円です（執筆時点の目安。為替で変動）。3台以内で足りるなら、Antivirus Plus（3台）の初年度$39.99も候補です。いずれも税別で、2年目以降の更新価格は初年度より高くなる場合があります。

支払いはカードとPayPalに対応し、カード決済では3D Secure 2.0の認証を求められることがあります。公式ヘルプは、日本発行のカードやJCBの可否には触れていません。

購入するたびに、請求書または支払領収書が請求先のメールアドレスへ届きます。PDFの取得先は、Bitdefender Centralです。別の入手先は、決済代行の2Checkout（Verifone）の注文画面。事業用として経費にする場合の消費税の扱いは、税理士に確認してください。

自動更新の停止と返金申請はCentralから進める

自動更新を止めるには、Bitdefender Centralの「My Subscriptions」を開きます。次に開くのは、「My Payments」または「Subscriptions」。停止しても、支払い済みの期間が終わるまでは使い続けられます。

初回購入または自動更新から30日以内なら、返金を申請できます。購入後30日以内であれば、すぐに解約して返金を受けられます。次回の更新だけを止める操作とは、別の手続き。

Bitdefenderが向いている人・向いていない人

複数OS・複数台をまとめて守りたい人には、Bitdefenderが候補になります。価格はUSD建てで、窓口は日本語対応をうたっていません。どちらも受け入れられるかが分かれ目。日本語の有人サポートや円建ての国内購入を優先するなら、ESETやNortonも比べてください。

複数OSの端末をまとめたいなら候補に残しやすい

  • Windows、Mac、Android、iPhoneが混在していて、1つの契約で守りたい人
  • 3台以内ならAntivirus Plus、それ以上ならTotal Securityと、台数で製品を選び分けたい人
  • 日本語の画面は管理画面とスマホアプリで足りる人

従業員の端末までまとめて管理したい場合は、個人向けとは別の法人向け製品を検討してください。

日本語サポートを優先するならESETやNortonも比較する

日本語の担当者に相談したい人や、円建てで買いたい人には、ESETとNortonも候補です。

ESET HOMEとWindows・macOS・Android向け製品は、日本語で使えます。キヤノンITソリューションズの日本語サポート窓口もあります。価格は円建てで、Essentialは1台1年¥4,950（税込）から。月額版も選べます。30日間の無料体験は1回限りで、VPNは対象外です。

Norton 360アプリと製品マニュアルには、日本語版があります。チャットや電話の入口は、日本語の公式サポートサイト。体験版は支払い方法の登録が必要で、終了後に有料ライセンスへ自動更新される場合があります。

日本向け公式ストアでは、初年度価格と更新価格が分けて示されています。Norton 360 Standard（2台）は初年度¥5,480（税込）で、翌年以降は¥8,980です。

まとめ：評判だけで決めず、自分の端末とサポート条件で選ぶ

独立した第三者機関の試験では、Bitdefenderの防御性能が高く評価されています。ただし、契約を決める材料は評判だけではありません。対象OSと日本語対応に加え、動作や更新条件も選ぶ基準。

契約前に確認する4項目

  1. 守りたい端末のOSと台数が、選ぶ製品の対象に収まっているか
  2. 初回スキャン後の普段の作業で、動作が重くならないか
  3. 使う製品が日本語で表示されるか、問い合わせが英語になっても困らないか
  4. 初年度価格と更新価格の差、自動更新の止め方、30日以内の返金条件

無料版・体験版で相性を確かめる

Windows 1台ならAntivirus Freeから始められます。Macやスマートフォンまで試すなら、対象はカード登録不要のTotal Security 30日間体験。合わなくても、30日後にそのまま失効します。
