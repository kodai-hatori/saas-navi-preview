Gamma AI（gamma.app）の料金【2026年】無料でどこまで使える？AIクレジットの仕組み

Gamma（Gamma AI）は、AIでプレゼン資料を組み立て、PPTXやPDFへ書き出せるツールです。Freeならカード登録も要りません。

この記事では、無料枠の400クレジットと有料プランの違いを紹介します。支払い方法や解約・返金の条件も分かります。

Gammaの料金プランは個人向け4種類・法人向け2種類

  • Free：￥0／登録時400クレジット
  • Plus：月￥1,440〜／毎月1,000
  • Pro：月￥2,500〜／毎月4,000
  • Ultra：月￥13,274〜／毎月20,000
  • Business：月￥5,900／1ユーザー
  • Enterprise：個別見積もり／年間契約

Gammaの料金ページを見る →

料金ページでは個人向けとビジネス向けを切り替えられます。年払いと月払いの価格も見比べられます。

日本語の料金ページには、個人向けのFree・Plus・Pro・Ultraが円建てで並んでいます。

無料プランでできること・できないこと（400クレジット・10枚上限・PPTX書き出し）

Freeにも、スライドの自動生成が含まれます。PowerPoint（パワポ）形式への書き出しも可能。主な制限は、補充されない400クレジットです。さらに、1回10枚までの上限があり、書き出したファイルにはGammaのロゴが入ります。

400クレジットは登録時の1回だけ

サインアップ時にもらえるのは400クレジットで、毎月の補充はありません。AIクレジットは、GammaのすべてのAI機能で共通。ドキュメントや画像にも使うため、試す形式が増えるほど早く減ります。AIの処理がエラーになったときは、クレジットは減りません。

使い切った後の選択肢は、有料プランへの切り替えか友達招待。友達を招待すると、クレジットをもらえます。追加クレジットを買えるのは有料ユーザーだけ。Freeのままでは買い足せません。購入したクレジットは、有料プランを続けている間は失効しません。

1回のプロンプトで作れるのは最大10枚

1回のプロンプト（AIへの指示）から作れるスライドは最大10枚です。Plusに切り替えると、この上限は100枚まで広がります。

研修資料や提案書が数十枚になる場合、1回の指示では作りきれません。10枚を超える資料をまとめて生成したいなら、有料プランが候補になります。

PPTX・PDF・PNG・Googleスライドへの書き出しは無料でも可能

作った資料は、無料プランでもPPTX（PowerPoint）・PDF・PNGでダウンロードできます。Googleスライドへの書き出しにも対応。手元のPowerPointファイルやPDFを読み込み、作り直すことも可能。無料プランで書き出したファイルにはGammaのロゴが入ります。ロゴを外せるのはPlus以上です。

社内用なら、ロゴ入りでも支障は少ないでしょう。取引先に渡す資料では、ロゴを外したいところ。ロゴの要否が、無料プランで足りるかを分ける明確な基準です。

Freeで使える書き出し形式と、Plusで外せるロゴの違いが分かります。

400クレジットの消費量は、資料の内容によって変わります。まず本番に近い資料を1本作り、作成前後の残高を比べてみてください。その差が、月間消費量の目安。月1,000以内ならPlus、毎月超えるならProが候補です。高度な画像モデルでは消費量が変わるため、この試算は目安にとどめます。

AIクレジットの仕組みと繰り越しのルール

AIクレジットは、GammaのAI機能を使うたびに減っていく持ち点です。Freeは最初の400だけ、有料プランは毎月決まった量が付与され、有料でも使い放題にはなりません。

1回の操作で使うクレジットは、作業の内容やAIモデルによって変わります。生成する内容の長さや複雑さも影響するため、「400クレジットでスライド何枚分」という決まった換算はありません。

プランごとに付与されるクレジットは次のとおりです。

  • Free：登録時に400（補充なし）
  • Plus：毎月1,000
  • Pro：毎月4,000
  • Ultra：毎月20,000
  • Business：1ライセンスあたり毎月10,000（ほかにワークスペースで共有するクレジットあり）

有料プランでは、使い切れなかったクレジットを翌月以降に持ち越せます。手元に残せるのは毎月の付与量の2倍まで。Plusなら2,000クレジットが上限です。それでも足りない月は、有料ユーザーに限り追加で購入できます。

Plus・Pro・Ultra・Businessの料金とできることの違い

ひとりで使う場合は、まずPlusとProを比べます。APIやカスタムドメインが必要か、毎月何クレジット使うかが分かれ目です。

  • Free：￥0
  • Plus：年払いで月￥1,440（年額￥17,280）／月払いで月￥1,800
  • Pro：年払いで月￥2,500（年額￥30,000）／月払いで月￥3,500
  • Ultra：年払いで月￥13,274（年額￥159,291）／月払いで月￥14,750
  • Business：年払いで月￥5,900（年額￥70,800）
  • Enterprise：個別見積もり（年間契約）

FreeとEnterprise以外は、いずれも1ユーザーあたりの金額です。居住地域に応じた税金が加算されます。

Plus：個人の本格利用向け

Plusでは、書き出した資料からGammaのロゴを外せます。1回の指示で作れるスライドも最大100枚に増加。画像づくりには、無料プランより高度なAI画像モデルを使えます。

ロゴなしで資料を社外に出せるプランのうち、いちばん安いのがPlusです。取引先に渡す資料をGammaで作るなら、最初に検討するのはこのプランです。

Pro：一番人気、対外資料やAPIも使うなら

Proは、公式が「一番人気」と位置づけるプランです。プレミアムAI画像モデルとカスタムブランディングが加わり、詳細な分析や高度な共有機能も使えます。独自ドメインでの公開は最大10個までで、APIも利用可能。ロゴを外すだけならPlusで十分です。自社ドメインでの公開や分析まで必要なら、Proが候補になります。

PlusとProを選ぶ基準は、毎月使うクレジットの量です。月1,000で足りるならPlusで十分。余った分は2,000まで残せるため、多く使う月は前月までの残りで補えます。それでも毎月追加購入するなら、月4,000が付くProへの切り替えどきです。年払いどうしの差額は月￥1,060。プランは「設定＆メンバー」からいつでも変更できます。まずPlusを選び、足りなくなってからProへ上げても間に合います。

Ultra・Business：大量生成やチーム利用向け

Ultraは個人向けの最上位プランで、毎月20,000クレジットが付きます。テキスト・画像・動画の生成には、最先端AIモデルを使えます。独自ドメインでの公開は最大100個。新機能への早期アクセスも含まれます。Proの月4,000では足りない人や、動画生成モデルを使いたい人向けです。価格は年払いでも月￥13,274。Proの5倍を超えます。

Businessには、SSO認証とSOC 2関連のドキュメントが含まれます。最先端AIモデルと高度なデータコントロールも対象。クレジットは1ライセンスあたり毎月10,000です。ワークスペースで共有する分も別に付きます。

Gammaの料金ページを見る →

各プランの月額や付与クレジットを一覧で見られます。使えるAIモデルも掲載されています。

SSOやSOC 2のドキュメントが不要なら、まずProと比べます。高度なデータコントロールが要らない場合も同じです。1人あたりの年額は、Proが￥30,000でBusinessが￥70,800。その差は、1人につき年￥40,800です。

年払い・月払いの差と日本からの支払い方法

1年使い続けるなら年払いのほうが安く、Proなら年￥12,000の差になります。日本からの支払いは、クレジットカードかデビットカードが基本です。

月払いを12か月続けた総額と年払いを比べると、次のとおりです。

  • Plus：月払い12か月で￥21,600、年払いは￥17,280（差額￥4,320）
  • Pro：月払い12か月で￥42,000、年払いは￥30,000（差額￥12,000）
  • Ultra：月払い12か月で￥177,000、年払いは￥159,291（差額￥17,709）

年払いのほうが得になるのは、Plusなら10か月以上使う場合です。Proは9か月以上、Ultraは11か月以上が目安。年払いでは1年分をまとめて支払います。Plusでも、申し込み時には￥17,280が必要です。利用期間が未定なら月払い、1年使うと決めているなら年払いが向きます。

支払い方法として案内されているのは次の4つです。

  • 主要なクレジットカード・デビットカード（JCBが使えるかの明記はなし）
  • 米国・EUの銀行口座からの直接支払い
  • UPI決済（インドのみ）
  • 発注書と支払い条件による取引（Enterpriseのみ）

日本の銀行振込や請求書払いに当たるのは、この発注書による取引だけです。Businessを含むほかの有料プランは、カード払いが前提。料金ページには、住んでいる地域に応じて税金が加算されると記載されています。

請求書は、Stripeの請求履歴からPDFでダウンロードできます。設定で「Billing」を開き、「Manage subscription in Stripe」へ進んでください。手順は、どの有料プランでも共通。発行済みの請求書は、後から編集できません。請求書に載せたいVAT・税番号は、サインアップ時に入力しておきます。経費にする場合の消費税の扱いは、税理士へ確認してください。

解約・ダウングレードの手順

解約もダウングレードも、Gammaの画面からいつでも自分で手続きできます。解約しても、現在の請求期間が終わるまでは有料プランの機能とクレジットを使い続けられます。

解約後にFreeへ移るまでの流れは、次のとおりです。

  1. Gammaの「設定＆メンバー」を開き、有料プランを解約する
  2. 現在の請求期間が終わるまでは、有料機能と残りのクレジットをそのまま使える
  3. 請求期間が終わると、自動的にFreeプランへ移る
  4. 作った資料は解約後も開ける（一部の高度な機能は制限される場合がある）

2025年12月1日以降、返金申請の期限は有料プラン加入から3日以内です。Gammaは、期限内にサポートへ申請した場合に限り返金します。月払い・年払いのどちらも、全額返金の対象。ただし、使ったクレジットがプランごとの上限を下回っていることが条件です。

  • Plus：200クレジット未満
  • Pro：600クレジット未満
  • Ultra：2,000クレジット未満
  • Business：1,000クレジット未満

解約しただけでは、3日以内でも返金されません。法令上必要な場合を除き、3日を過ぎてからの返金もありません。年払いの残り期間も、返金の対象外。ヘルプセンターには日本語版があります。ただし、返金を申請する窓口の日本語対応は明記されていません。

ダウングレードも、同じ「設定＆メンバー」から手続きします。変更後に使えるのは、移行先のプランに含まれる機能だけ。ProからPlusに下げると、APIアクセスとカスタムドメインが外れます。手続き前に、両プランの機能を見比べてください。

CanvaやBeautiful.aiと比べてGammaの料金は高いか

最も安い有料プランの年額を比べると、GammaはCanvaより高めです。ただし、Canvaはデザイン全般を扱うツール。GammaはAIで資料一式を組み立てるため、料金に含まれる機能が違います。同じくAIでプレゼンを作るBeautiful.aiも比較対象。年払いのProはほぼ同じ水準ですが、月払いではGammaのほうがかなり安くなります。

Canvaと比べると

日本語の料金ページには、無料プランのほかCanvaプロとCanvaビジネスが表示されています。

Canvaの日本向け価格は、Proが1人あたり年￥11,800です。Businessは1人あたり年￥18,800。Gamma Plusの年額￥17,280より、Canva Proのほうが安くなります。Gamma Proの年額￥30,000は、Canva Businessよりも高額です。

AIを使える量の決まり方も違います。CanvaのAI機能には、利用回数の上限があります。無料プランは、標準・高品質モデルの合計20回まで。Proは高品質モデルで200回、最高品質モデルなら20回まで使えます。

Canvaは無料プランでも、5GBのクラウドストレージと160万点以上のテンプレートを使えます。支払いは、JCBを含む国際ブランドのカードとPayPalに対応。請求書もアカウント設定からPDFで取り出せます。Gammaと異なり、CanvaはJCB対応を明記し、PayPalも選べます。

Beautiful.aiと比べると

英語のトップページには、無料トライアルとデモの入口が表示されています。

Beautiful.aiには常設の無料プランがありません。試せるのは14日間の無料トライアルです。個人向けのProは、年払いで月$14.50。1ドル=157円換算では約2,300円（為替で変動する目安）です。Gamma Proの年払い（月￥2,500）とほぼ同じ水準に収まります。

差が大きいのは月払いです。Beautiful.aiのProは単月でも契約でき、料金は月$45（約7,000円）。月￥3,500のGamma Proと比べて約2倍です。一方、Beautiful.aiでは全プランのAI生成が無制限。毎月のクレジットで利用量が決まるGammaとは、料金の仕組みが異なります。PowerPointファイルの読み込みと書き出しには、どちらも対応。Gammaには日本語の料金ページがありますが、Beautiful.aiの公式サイトは英語です。

よくある質問

加入後に合わなかったら返金してもらえる？

加入から3日以内にサポートへ申請すると、全額返金の対象になります。月払い・年払いのどちらも対象です。ただし、使ったクレジットがプランごとの上限未満であることが条件。Gammaには有料プランの無料トライアルがなく、Freeが試用枠です。無料では試せないPro専用機能は、次のとおりです。

  • カスタムブランディング
  • カスタムドメイン
  • API

これらを試すなら、月払い（月￥3,500）で契約し、3日以内に目的の機能を確かめます。返金申請の条件は、Proの使用量が600クレジット未満であること。3日を過ぎても、次の請求日より前に解約すれば翌月からの支払いは止まります。

余ったAIクレジットは繰り越せる？

有料プランなら繰り越せます。上限は毎月の付与量の2倍、つまり2か月分まで。Proは8,000、Ultraは40,000クレジットまで持てます。登録時の400クレジットは1回きり。繰り越せるのは、有料プランの月間クレジットに限られます。上限いっぱいまで余る月が続くなら、ひとつ下のプランも候補です。

解約すると作った資料は消える？

消えません。解約やダウングレードの後も、作った資料にはそのままアクセスできます。制限される可能性があるのは、一部の高度な機能だけ。ロゴの削除は有料プランの機能です。ロゴなしのPPTXやPDFを手元に残すなら、請求期間内に書き出しておきましょう。

まとめ

無料プランでは、登録時にもらう400クレジットがAI機能の試用分になります。有料にするかどうかの判断材料は、ロゴを外したいか、1回に10枚を超えて作るか、クレジットが足りるかの3つです。

  • 社内向けでロゴが入っても困らず、AIでの生成が400クレジットに収まる：無料プランのまま
  • ロゴなしで社外に出したい、10枚を超える資料を一度に作りたい：Plus（年払いで月￥1,440）
  • 月1,000クレジットでは足りない、APIやカスタムドメインを使う：Pro（年払いで月￥2,500）
  • SSOやSOC 2のドキュメント、高度なデータコントロールが必要：Business（年払いで1ライセンス月￥5,900）
