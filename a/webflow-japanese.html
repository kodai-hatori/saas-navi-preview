Webflowは日本語で使える？UIの日本語化とサイト制作・サポートの対応範囲

開発・インフラ・データ 7,567字
#Webflow #Web制作 #ノーコード #海外SaaS

Webflowを候補にして管理画面を開くと、並んでいるのは英語のメニューです。日本語のサイトを本当に作れるのか、チームで運用できるのかと不安になる人は少なくありません。「Webflow 日本語化」で情報を集めても、Chrome拡張、ブラウザ翻訳、公式のLocalizeといった別々の話が混ざって出てきます。

ここでは「日本語で使える」を管理画面、サイト制作、多言語化、サポートに分け、日本からの契約実務まで整理します。Webflowを無料で試すか、日本語UIのツールと比べるかを決める材料にしてください。

公式サイトで料金を見る

無料のStarterでできる範囲と、独自ドメインで公開するときに必要な有料プランの条件を確認できます。

結論：Webflowの日本語対応は用途ごとに異なる

Webflowでは日本語のサイト本文やCMSを扱えますが、公式の日本語管理画面と日本語の有人サポートは、公開されている公式情報からは確認できません。管理画面の表示を補う第三者のChrome拡張と、訪問者向けのWebflow Localizeは別の仕組みです。

「日本語化」が指す対象ごとに、状況は次のように分かれます。

  • 公式の管理画面UI：日本語を表示言語として選べるという公式案内は見当たらない
  • 第三者のChrome拡張：管理画面の英語表示を日本語に置き換える補助手段
  • 日本語サイトの制作：本文、CMS、フォーム、SEO設定に日本語を使える
  • Webflow Localize：公開サイトを言語・地域別に展開する追加機能
  • 日本語サポート：英語のHelp Centerはあるが、日本語の有人対応は確認できない

管理画面の日本語化と日本語サイト制作は別

Designerやサイト設定の画面が英語であることと、完成したサイトに日本語を表示できるかは、別の問題です。Webflowのページ本文やCMSの項目には日本語を入力でき、サイトの言語コードも日本語に設定できます。

導入を決めるときは「操作する人が英語画面で作業できるか」と「公開するサイトを日本語で作れるか」を切り離して考えます。

Webflow Localizeは管理画面の翻訳機能ではない

Webflow Localizeは、公開サイトの本文や画像、表示条件、SEO設定を言語・地域ごとに切り替える機能です。訪問者が見るページを多言語にするためのもので、管理画面を日本語で操作したい人が契約しても目的は果たせません。

Webflowの管理画面を日本語化する方法

管理画面を日本語で表示したいなら、第三者が提供するChrome拡張を使う方法があります。拡張を入れない場合は、Chrome標準の翻訳で部分的に補えます。どちらもWebflow公式の言語設定ではないので、導入前に提供元と対応範囲を確かめてください。

Chrome拡張「Webflow 日本語化」を導入する

Chrome Web Storeで「Webflow 日本語化」を検索すると、IGNITE Co., Ltd.が開発した拡張機能が見つかります。同じ名前の拡張を案内している別の会社もあるため、掲載ページの提供元表示で見分けてください。導入の流れは次のとおりです。

  1. ChromeでChrome Web Storeを開き、「Webflow 日本語化」の掲載ページを表示する
  2. 提供元がIGNITEであることと、要求される権限を確認してから「Chromeに追加」を選ぶ
  3. Webflowにサインインし、ダッシュボードとDesignerを開く
  4. メニューや設定パネルが日本語で表示されているかを確かめる

開発元のIGNITEは、この拡張を無料で提供すると案内しています。日本語になるのはダッシュボード、Designer、Site Settingsなどの画面です。開発元の説明によると、CMS、Body、Div Blockといった用語はあえて英語のまま残しています。英語の公式ヘルプと用語がそろうので、調べものの際に取り違えが起きにくくなります。

Chrome標準翻訳で補う

拡張を入れたくない場合は、画面上で右クリックして「日本語に翻訳」を選び、Chromeのページ翻訳で表示中のテキストを訳せます。

ただし汎用の翻訳は、Webflow固有の用語を文脈なしに訳します。「Collection」や「Div Block」が不自然な日本語になったり、パネルの表示が崩れたりするため、意味を知りたい画面だけで使うのが無難です。

拡張機能を入れる前に確認すること

翻訳拡張は、ログイン後の画面の文字を書き換えて動きます。Chrome Web Storeの掲載ページでは、IGNITEの拡張の最終更新は2026年2月です。Webflowが画面を変えると、翻訳が追いつかない箇所が出る可能性があります。業務アカウントで使うなら、次の2点は導入前に見ておきます。

  • 掲載ページに表示される権限の内容と、社内のブラウザ拡張の利用ルールに合うか
  • 翻訳されずに英語のまま残る画面があっても作業に支障がないか

表示の崩れや動作の不具合が拡張に起因する場合、Webflowの公式サポートは拡張を無効にして確かめるか、提供元に問い合わせるよう案内しています。拡張の不具合はIGNITEに問い合わせる前提で使ってください。

Webflowで日本語サイトを作るときの設定と注意点

管理画面の言語とは関係なく、Webflowでは日本語の本文、CMS、フォーム、SEO設定を持つサイトを制作できます。仕上がりの品質は、言語コード、フォント、行間、改行、フォームの文言まで確認して整えます。

日本語の本文・CMS・フォームを設定する

日本語サイトとして公開するなら、日本語にしておくべき要素はページ本文だけではありません。

  • ページ本文、ボタン、ナビゲーションの文言
  • CMSのコレクションに登録する記事や商品情報
  • フォームのラベル、送信ボタン、送信後の成功・エラーメッセージ
  • 各ページのSEOタイトル、メタディスクリプション、画像のalt
  • 言語コード：Localizeパネル > Localesで主要ロケール（primary locale）の言語を日本語にすると、jaが割り当てられる

言語コードはブラウザや検索エンジンにページの言語を伝える設定です。現在のWebflowでは、Site settingsに残る旧来の言語コード欄より、Localizeパネルの主要ロケールの設定が優先されます。英語圏向けのテンプレートを使うなら、フォームやフッターに英語の初期文言が残っていないかも見直します。

日本語フォントと改行を端末別に確認する

Webflow Marketplaceには無料と有料のテンプレートがあります。有料テンプレートはSite planとは別の一回払いで、ライセンスは原則として1案件に限られます。欧文を前提にデザインされたテンプレートに日本語の本文を流し込むと、見出しが途中で折り返したり、行間が詰まって見えたりしがちです。選ぶ段階で、日本語を入れたときの見え方まで想定しておきます。

公開前には、パソコンとスマートフォンの両方で、日本語フォントの表示、行間、見出しの折り返し、行頭に句読点が来ていないかを確かめます。

多言語サイトにはWebflow Localizeを使う

日本語と英語など、複数の言語・地域向けにサイトを出し分けたい場合はWebflow Localizeを使います。locale（言語・地域の設定）ごとに、本文、画像、表示・非表示、SEO設定を切り替えられます。

日本語に加えて別の言語を出すときは、Site planとは別に有料のLocalizeプランが必要です。料金はEssentialが月$9から、Advancedが月$29からで、利用量によって変わります。日本語だけで公開するサイトなら、有料のLocalizeプランは日本語以外の言語を追加すると決めた段階で検討すれば間に合います。

日本語で学べる資料とサポートの範囲

公式のWebflow UniversityとHelp Centerは学習と自己解決に使えますが、確認できる公式ページは英語です。国内の日本語解説記事や制作会社の支援は、Webflow公式の日本語サポートとは分けて考えてください。

公式教材はブラウザ翻訳も使って学ぶ

Webflowの公式リソースは、役割ごとに分かれています。

  • Webflow University：動画とレッスンで操作を体系的に学ぶ教材
  • Help Center：機能ごとの設定手順や請求の仕組みを調べるヘルプ
  • コミュニティフォーラム：ユーザー同士で質問し合う場

英語が得意でなくても、ページをChromeで翻訳して読み、操作名だけは英語のまま覚えれば学習は進められます。

日本語の学習資料と日本語有人サポートは別

国内の制作会社や個人による日本語の解説、講座、制作支援は、Webflow公式の窓口ではありません。Webflow公式の日本語有人サポートは公開情報から確認できません。ただ「対応していない」とも言い切れないので、日本語での問い合わせを導入条件にするなら契約前に確かめておきます。

料金と始め方：無料プラン、支払い、請求書、解約

Starter SiteとStarter Workspaceは無料で始められ、日本からは主要なカードでUSD決済できます。有料化するときは、サイトごとのSite planとチーム単位のWorkspace planが別契約になる点を押さえておきます。

無料のStarterから始める

登録すると無料のStarter Workspaceが付与され、サイトは無料のStarter Siteで作り始められます。公開先はWebflow.ioのサブドメインで、静的ページは2ページ、CMSアイテムは50件までです。管理画面の操作感と、日本語の本文やCMSの表示を確かめるには十分な範囲です。無料のStarter WorkspaceはFull seatが1つだけです。複数人で編集するなら、Workspace plan（Core $19/月、Growth $49/月。いずれも年払いの月額換算）に切り替え、必要に応じてseat（Full $39/月、Limited $15/月。年払い）を追加します。

独自ドメインで公開するには、サイトごとに有料のSite planが必要です。CMSを使わない静的サイトならBasicで、年払いで月$15（月払いは$25）。ブログやお知らせなどCMSを使うなら、BasicにはCMSがないためPremiumを選び、年払いで月$25（月払いは$39）です。1ドル=159円換算で、Basicは約2,385円、Premiumは約3,975円になります（執筆時点の目安で、為替により変動します）。

公式サイトで料金を見る

Starterの上限、BasicとPremiumの違い、年払いと月払いの差を確認できます。

日本からの支払いと請求書

Webflowは日本から公式サイトで申し込めます。Visa、Mastercard、American Express、Discover、JCB、Diners Clubのクレジットカード・デビットカードに対応しています。請求はUSDで、表示価格には適用税が別途加算されます。

請求書は、Workspace設定のBillingからWorkspace、Site、Seat、Add-onごとにPDFでダウンロードできます。表記はUSDのみで、複数のSite planやWorkspace planの請求を1枚にまとめられません。USD建ての請求書を消費税やインボイス制度の上でどう扱うかは、税理士に確認してください。

Site planとWorkspace planを解約する

解約は、契約ごとに別の設定画面から行います。

  • Site plan：Site settings > Plansから無料のStarterへダウングレードする
  • Workspace plan：Workspace settings > Plansから無料のStarterへダウングレードする
  • 別契約の扱い：片方を解約しても、もう片方の契約と自動更新は止まらない
  • 解約後の利用：原則として当期の終わりまで使える

SiteまたはWorkspaceを初めて新規購入した場合に限り、購入から14日以内なら返金を申請できます。更新料、Add-on、seat、Marketplaceでの購入は対象外です。

Site planとWorkspace planの区分と請求周期を、契約前に確認できます。

日本語運用を優先する場合の代替候補

公式の日本語UIと日本語サポートを重視するならStudio、日本語の情報量と運用の自由度を重視するなら、自分でサーバーに設置するWordPress（WordPress.org版）が候補です。Framerは日本語のLocalizationに対応していますが、エディタの日本語UIは確認できないため、日本語化を目的とした乗り換え先とは言い切れません。

Studioは公式の日本語UIとサポートを重視する人向け

  • 日本語UI：管理画面、エディタ、公式ヘルプが日本語
  • 日本語サポート：ログイン後のチャットサポート、法人向け相談窓口
  • 運用方式：ホスティング込み。料金はサイト（プロジェクト）単位

日本居住者は円建て・税込で契約でき、JCBのカードも使えます。請求書と領収書はダッシュボードのお支払い履歴から取得でき、適格請求書の発行についても案内があります。無料のFreeでも50ページまで公開できますが、独自ドメインを接続するにはMini以上が必要です。Miniは年払いで月¥590（税込、月払いは¥1,290）です。支払い済みの料金は原則として返金されません。初回購入から14日以内なら返金を申請できるWebflowとは、この点が異なります。

公式サイトで料金を見る

プランごとのページ数やCMSの上限を、日本語の料金ページで見比べられます。独自ドメインで公開する前に、作りたいページ数が収まるプランかを確かめておくと安心です。

WordPressは日本語情報と運用自由度を重視する人向け

  • 日本語UI：日本語ローカライズ版を配布し、日本語の公式サイトとドキュメントがある
  • 日本語サポート：日本語のサポートフォーラム。コミュニティによる回答で、有償の有人サポートではない
  • 運用方式：自前のホスティングとドメインが必要

ソフトウェア本体はGPLで公開されており、商用利用でもライセンス料はかかりません。その代わり、サーバーとドメインは各事業者と別に契約し、更新、バックアップ、セキュリティ対策も構成に応じて自分で担います。

公式サイトで料金を見る

費用の大半はサーバーとドメインの契約で決まります。使う予定のレンタルサーバーの料金と並べて見積もると、Webflowの月額と比べやすくなります。

Framerは日本語UIの代替と決めつけない

  • 日本語UI：エディタを日本語表示にできるかは確認できない
  • 日本語サポート：日本語での問い合わせ対応は確認できない
  • 運用方式：ホスティング込み。料金はUSD基準で表示

FramerのLocalizationは日本語を含む238の言語・地域に対応し、公開サイトを多言語化できます。ただしWebflow Localizeと同じく訪問者向けの機能で、英語の画面を避けたいという理由で乗り換えても、状況は変わらない可能性があります。料金は無料のFreeのほか、独自ドメインを使えるBasicが年払いで月$10です。日本発行のカードやJCBで支払えるかは、公式情報に明記がありません。

Webflowの日本語対応でよくある質問

公式の言語設定、拡張機能の安全性、問い合わせの窓口について補足します。

Webflowに公式の日本語切り替え設定はありますか？

公開されている公式情報からは、管理画面の表示言語を日本語に切り替える設定を確認できません。公式のHelp Centerも英語版だけで、日本語版のページは用意されていません。「存在しない」とまでは言い切れないものの、日本語で操作したいなら、現時点ではIGNITEの拡張かChromeのページ翻訳を前提に考えるのが現実的です。

Chrome拡張は無料で安全ですか？

料金は無料です。開発元のIGNITEは、利用者のデータを収集・使用しないと表明しています。ただし、これは開発元の説明で、第三者が安全性を保証したものではありません。会社のアカウントで使うなら、掲載ページに表示される権限を社内のルールと照らし合わせてから入れてください。

日本語で問い合わせできますか？

公式の窓口は、Support Portalから送った問い合わせにメールで回答する方式と、AIのサポートアシスタントによるチャットです。チャットで担当者につながるかは、内容と時間帯によります。電話やビデオでの対応はEnterpriseだけなので、ほとんどの利用者は英語のメールかチャットで問い合わせることになります。

まとめ：日本語にしたい対象を決めてから選ぶ

日本語サイトを作ることが目的なら、Webflowは候補に残せます。管理画面は第三者のChrome拡張で補えますが、公式の日本語UIや日本語の有人サポートを必須にするなら、StudioやWordPressとも比べてから決めてください。

Webflowが向く人

次の条件に当てはまるなら、無料のStarterから試す価値があります。

  • 日本語の本文やCMSを、デザインの自由度を保ったまま作りたい（CMSを使うならPremiumの費用を見込める）
  • 英語の管理画面か、第三者拡張による日本語表示で作業できる
  • 英語の公式教材とヘルプを、翻訳を使いながら参照できる
  • USD建てのカード決済と、契約ごとに分かれた請求書で経理処理できる

日本語UIを優先して比較したい人

次のような条件があるなら、Webflowに決める前にほかのツールも比べたほうが確実です。

  • チーム全員が日本語の画面で操作する必要がある
  • 日本語で公式窓口に問い合わせられることが導入の条件
  • 円建ての請求や適格請求書が経理上必要

この場合はStudioとの比較から始め、サーバーの運用まで担えるならWordPressも候補に加えます。Webflowも並行して試すなら、無料枠で操作感を確かめてから有料化を判断できます。
