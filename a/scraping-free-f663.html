スクレイピングツールは、Webページから必要な情報を集め、CSVなどへ出す作業を助けます。無料で始められても、常設プラン、月次クレジット、期限つきトライアルでは使える範囲が違います。

ここでは5製品の無料枠と、有料プランへ切り替える目安を紹介します。

無料で使えるスクレイピングツール5選の早見

コードなしで少量から試すなら、月次無料枠のある製品が候補です。API連携まで考えるなら、Bright Dataの無料対象製品も比べてみてください。

  • Bright Data：対象製品に月次クレジット
  • Browse AI：毎月50クレジット
  • Octoparse：10タスク・月5万行
  • ParseHub：1回200ページ
  • Web Scraper：ローカル実行は無料

迷ったときの選び方

コードなしで少量を集めるならBrowse AI、日本語の画面を優先するならOctoparseが候補です。

API連携ならBright Data、デスクトップアプリならParseHub、Chromeでのローカル実行ならWeb Scraperが候補です。

無料プラン・月次クレジット・無料トライアルの違い

継続して無料で使えるプランにも、実行回数や取得件数の上限があります。無料トライアルには期限があるため、同じ「無料」でも条件を分けて選びましょう。

  • 無料プラン：期限なく使えるが、機能や件数に上限がある
  • 月次クレジット：毎月補充され、使う機能ごとに消費量が違う
  • 無料トライアル：一定期間だけ有料機能を試せる
  • 上限の単位：クレジット、タスク、行数、ページ数など
  • 期限後の扱い：製品ごとの契約条件を先に見る

期限なしで使える無料プラン

Browse AI、Octoparse、ParseHubには、利用期限のない無料プランがあります。ただし、Browse AIは毎月のクレジット、Octoparseはタスクと行数、ParseHubは1回のページ数が主な上限です。

無料でも、取得件数や機能は無制限ではありません。1回と1か月の取得量を先に見積もりましょう。

毎月リセットされる無料クレジット

Bright Dataでは、対象製品に共通する月5,000クレジットが新規アカウントへ付与されます。登録にクレジットカードは不要です。残高は毎月1日に5,000へ戻り、未使用分は翌月へ繰り越されません。

Web Unlocker APIやSERP APIなどは、同じ共通プールからクレジットを消費します。一方、Datacenter、ISP、Residential Proxiesは月次無料クレジットの対象外です。

期限つきの無料トライアル

Web Scraper Cloudには、クレジットカード不要の7日間トライアルがあります。OctoparseのStandardとProfessionalにも14日間の無料トライアルが用意されています。

トライアルは、有料機能を短期間で見極めるためのものです。継続無料プランとは分けて考えます。

無料で使えるスクレイピングツール5選

無料上限の単位は製品によって異なります。クレジット、行数、ページ数、ローカル実行のどれが自分の作業に合うかで選ぶのが近道です。

Bright Data｜対象製品に月次無料クレジット

Bright Dataの無料枠は、製品ごとに独立せず、1アカウント共通の月5,000クレジットです。

  • 無料の種類：対象製品共通の月次クレジット
  • 上限：毎月5,000クレジット
  • 実行場所：APIやブラウザ型など製品で異なる
  • 向く人：API連携や取得規模の拡大を考える人
  • 有料で広がる範囲：従量課金や月額プランで追加利用

消費単位も製品ごとに違います。Web Unlocker APIやSERP APIは1リクエスト、Web Scraper APIは1レコード、Scraper Studioは1ページロードにつき1クレジットです。Browser APIは1MBにつき5クレジットを使います。

対象外のプロキシ製品には、別枠で1回限り2ドル、7日間有効のトライアルクレジットがあります。

Browse AI｜コードなしで毎月50クレジット

Browse AIは、Web上の操作をロボットとして登録し、コードを書かずにデータを集めるツールです。無料プランでは毎月50クレジットを使えます。

  • 無料の種類：期限のないFreeプラン
  • 上限：月50クレジット・対象サイト2件
  • 実行場所：クラウド
  • 向く人：コードなしで少量から始めたい人
  • 有料で広がる範囲：クレジットと対象サイト数

ロボット数に制限はなく、ユーザーは3人まで利用できます。標準サイトでは10行で1クレジット、タスクごとに最低1クレジットを消費します。

Octoparse｜日本語UIで10タスクまで作成

Octoparseは管理画面とヘルプが日本語に対応し、Freeプランをカード不要で継続利用できます。

  • 無料の種類：期限のないFreeプラン
  • 上限：10タスク・月5万行
  • 実行場所：1台のPCでローカル抽出
  • 向く人：日本語で設定したい人
  • 有料で広がる範囲：クラウド抽出やAPI

無料版はローカル抽出が中心です。クラウド抽出、スケジュール、IPローテーション、APIが必要なら、有料プランが選択肢に入ります。

ParseHub｜1回200ページまで取得

ParseHubはデスクトップアプリ型です。無料プランはカード不要で、1回200ページまで取得できます。

  • 無料の種類：期限のないFreeプラン
  • 上限：1回200ページ・公開5プロジェクト
  • 実行場所：デスクトップアプリ
  • 向く人：ページ単位で上限を把握したい人
  • 有料で広がる範囲：非公開化と取得ページ数

無料版で使えるのは、公開プロジェクト5件までで、データ保持は14日です。非公開化や取得ページ数の拡大には有料版が必要です。

Web Scraper｜Chromeでローカル実行

Web ScraperのChrome拡張はアカウント不要で、ローカル実行を回数制限なく無料で使えます。

  • 無料の種類：Chrome拡張の無料利用
  • 上限：ローカル実行の回数制限なし
  • 実行場所：Chromeを開いたPC
  • 向く人：一度きりの取得を無料で行いたい人
  • 有料で広がる範囲：クラウド実行やAPI

取得結果はCSVまたはXLSXへ出せます。スケジュール、クラウド実行、API、Webhooks、プロキシ、チーム利用はCloud側の機能です。

使い方に合う無料ツールの選び方

最初に見るのは、月間の取得量と対象サイト数です。次に、プロジェクトを公開できるか、日本語UIやサポートが必要か、PCを開いたまま実行できるかを決めます。

コードなしで少量から試したい

Browse AI、Octoparse、ParseHubが候補です。Browse AIは対象サイト2件・月50クレジット、Octoparseは10タスク・月5万行、ParseHubは1回200ページまで無料で使えます。

ParseHubの無料版は公開プロジェクトに限られます。業務データを非公開で扱うなら、無料枠の大きさより公開範囲を先に見てください。

日本語の画面とヘルプを重視したい

日本語UIと日本語ヘルプが確認できるのはOctoparseです。英語の料金ページや設定画面を読みながら進めたくない人に合います。

Bright Dataには日本語サイトがありますが、管理画面全体の日本語対応範囲は確認できません。日本語の製品説明があっても、操作画面まで日本語とは限らないため、分けて考える必要があります。

API連携や取得規模の拡大を見込んでいる

APIを自社の処理へつなぐ予定があるなら、Bright Dataが候補です。無料クレジットの対象製品で消費量を見てから、従量課金や月額プランへ進めます。

ただし、Datacenter、ISP、Residential Proxiesは月次無料クレジットの対象外です。プロキシを使う予定なら、API製品と無料条件を混同しないでください。

Chromeだけで一度きりの取得をしたい

Web ScraperのChrome拡張が候補です。処理はPC上で実行するため、クラウドへ任せる機能とは別物です。

定期実行や、PCを閉じている間の処理にはCloud側の機能が必要です。

無料版でできないこと

無料版では、クラウドでの定期実行や大量取得が制限されます。ただし、制限の内容は製品ごとに違います。

PCを閉じたままの定期実行

Octoparseの無料版とWeb Scraperの無料拡張は、ローカル実行が基本です。PCを閉じたまま決まった時刻に処理したいなら、クラウド実行やスケジュール機能を含む有料版が候補になります。

Browse AIはクラウドで動きますが、無料プランは毎月50クレジットです。定期実行の回数と取得行数の両方から消費量を見積もってください。

大量取得と長期保存

Browse AIではクレジット、Octoparseでは月間行数、ParseHubでは1回のページ数が上限の基準です。ParseHubはデータ保持も14日までとなります。

1回に必要な件数と月間の合計を分けて数え、無料枠で足りるか判断します。

非公開プロジェクト・チーム・API

ParseHubの無料版で扱えるのは公開プロジェクトだけです。社内情報を含む処理を非公開で管理したいなら、有料版を検討してください。

OctoparseやWeb Scraperでは、APIが有料側にあります。Web Scraperのチーム利用もCloud側の機能です。無料枠だけで処理できても、共有方法が要件に合わないことがあります。

有料プランへ切り替える目安

有料化の境目は、各製品の無料枠で異なります。取得量だけでなく、対象サイト数、公開範囲、実行場所、必要な機能を製品ごとに見ます。

無料のままで足りやすいケース

一度だけCSVへ出すなら、Web Scraperの無料拡張が候補です。Octoparseは10タスク・月5万行の範囲で、PC上のローカル抽出が足りる場合に向きます。

Browse AIは月50クレジットに加え、対象サイト2件の上限もあります。Bright Dataは対象製品が月5,000クレジットに収まるかを見ます。

有料化を考える3つのサイン

  • 取得上限：Bright Dataの5,000クレジット、Browse AIの50クレジット・対象サイト2件、ParseHubの200ページを超える
  • 実行方法：Octoparseのクラウド抽出やスケジュール、Web ScraperのCloud機能が必要になる
  • 管理方法：ParseHubで非公開化する、Web ScraperでAPIやチーム利用を始める

同じ制限に何度も当たるようになったら、有料プランを比べるタイミングです。

契約前に支払いと解約条件を見る

有料プランの開始価格は、Browse AI Personalが年払いで月額19ドル換算、Octoparse Basicが月額39ドルです。ParseHub Standardは月額189ドル、Web Scraper Cloud Projectは年払いで月額50ドルとなります。

1ドル=157円換算では、順に約2,983円、約6,123円、約2万9,673円、約7,850円です。為替で変わるため、契約時の請求額とは異なる場合があります。

Browse AIはUSD決済で、日本発行のJCBを含む主要カードに対応しています。OctoparseはカードまたはPayPalで支払えます。Octoparseは解約後、契約期間の末にFreeへ戻ります。自動更新を止める場合は、更新の24時間前までに手続きします。

Bright Dataの月額契約分は返金されません。対象製品に付く無料クレジットの未使用分は翌月へ繰り越されず、毎月1日に5,000へ戻ります。事業での税務処理は、必要に応じて税理士に確認してください。

無料でスクレイピングするときの注意点

ツールで取得できても、そのデータを取得してよいとは限りません。対象サイトの利用規約や公開範囲を調べ、過度なアクセスを避けてください。

対象サイトの利用規約とrobots.txtを確認する

まず対象サイトの利用規約とrobots.txtを読み、機械的な取得に対する方針を調べます。ログイン後のページや、取得禁止が明記されたページを安易に収集するのは避けましょう。

アクセス制御の回避を前提にせず、許可された範囲で設計することが大切です。不明な点があれば、サイト運営者へ利用方法を問い合わせてください。

著作権・個人情報の扱いに注意する

公開情報でも、自由に再公開や販売ができるとは限りません。収集と取得後の利用は分けて考えます。

個人を識別できる情報を扱う場合は、とくに慎重な判断が必要です。個別案件の適法性が分からないときは、専門家へ相談しましょう。

短時間に大量アクセスしない

短時間に多くのリクエストを送ると、対象サイトへ負荷をかけます。実行間隔と取得件数を抑え、失敗時の再試行が連続しないように設定してください。

定期実行では処理履歴を残し、アクセス数の異常な増加を見つけられるようにします。

無料スクレイピングツールのよくある質問

無料枠には件数、期間、実行場所、機能の制限があります。目的と取得量に合わせて選びましょう。

完全無料で使い続けられる？

Browse AI、Octoparse、ParseHubには継続して使える無料プランがあります。Web ScraperのChrome拡張も、ローカル実行を無料で使えます。

Bright Dataは対象製品への月次無料クレジットです。すべての製品に共通する無料プランではありません。

コードを書かなくても使える？

Browse AI、Octoparse、ParseHubは、コードなしで始められます。一方、Bright DataのAPIやプロキシには接続設定が必要です。

Web Scraperもプログラムを書く必要はありませんが、取得範囲を決めるサイトマップの設定は必要です。

日本語で使える無料ツールは？

日本語UIと日本語ヘルプが確認できるのはOctoparseです。Bright Dataには日本語サイトがありますが、管理画面全体の日本語対応範囲は確認できません。

Browse AI、ParseHub、Web Scraperについても、日本語の管理画面やサポートを前提にせず選ぶ必要があります。

商用目的でも無料で使える？

無料プランの条件と対象サイトの規約は、分けて確認します。取得データの著作権や個人情報にも注意が必要です。

すべてのツールやサイトをまとめて「商用利用できる」とは判断できません。扱うデータと利用方法に応じて確認してください。

まとめ：無料枠の上限を決めてから試す

無料枠の数字だけでなく、実行場所や公開範囲も比べて選びましょう。5製品の分かれ目は次のとおりです。

最初に決める3項目

  • 実行方法：APIならBright Data、Chrome内の一度きりの取得ならWeb Scraper
  • 操作環境：コードなしならBrowse AI、日本語UIならOctoparse
  • 公開範囲：公開プロジェクトでよければParseHub、非公開化するなら有料版

無料枠を使った後の判断

実行後は、上限に当たった項目だけを見直します。取得量、対象サイト数、非公開化、クラウド実行のうち、どれが不足したかを切り分けると、必要な有料プランを選べます。
