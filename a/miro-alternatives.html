Miroの代替ツール7選｜乗り換える理由別に無料版の制限と日本語対応を比較

業務効率・PM・タスク 8,748字
#Miro #オンラインホワイトボード #FigJam #Canva #海外SaaS

Miroの無料版で編集できるボードが足りない。メンバーが増えて請求額が気になる。社内ツールとは別に、ホワイトボードだけの契約を持ち続けたくない。Miroを離れたい理由はチームごとに違い、理由が違えば移る先も変わります。

ここでは、Miroの代わりになるホワイトボード7つを「無料版でどこまで使えるか」と「画面を日本語にできるか」でMiroと並べました。どれを無料版で試すか、Miroに残るかを決める材料にしてください。

結論：Miroから乗り換えるなら、不満の理由で行き先を決める

乗り換え先は「なぜMiroを離れたいか」で決まります。無料版の制限に困っているのか、社内の標準ツールに揃えたいのかで、候補はほとんど重なりません。

  • 無料のままボードを増やしたい → Canva（中身が簡単な図ならWhimsicalも）
  • 編集する人の費用を抑えたい、デザインチームでFigmaを使っている → FigJam
  • Microsoft 365・Teams、またはZoom Workplace Business以上をすでに契約している → Microsoft Whiteboard／Zoom Whiteboard
  • Miroのボードを移して、業務フロー図などの図解まで進めたい → Lucidspark
  • 英語の画面でもよく、ワークショップの設計手法を取り入れたい → Mural
  • 日本語の窓口がほしい → 代替ツールでは改善しないため、まずMiroに問い合わせる

編集するボードが少なく、Miroの操作に慣れているなら、無料版やStarterのまま残るのも1つの答えです。

乗り換えを決める前に、今のプランで編集できるボード数と契約人数を確かめておくと、候補と比べるときの基準になります。

Miroの代わりを探す主な理由と、理由ごとの候補

Miroを離れる理由は、大きく4つに分かれます。どれに当てはまるかが分かれば、次に見るツールも絞れます。

無料版で編集できるボードが足りない

Miroの無料版（Free）で編集できるボードは3件です。進行中のプロジェクトが4つ以上あると、古いボードを整理しながら回すことになります。代替ツールの多くも無料版は「3つまで」なので、制限のかけ方がMiroと違うツールを選ぶ必要があります。

  • この理由なら候補は Canva（条件つきでWhimsical）

人数が増えるほど費用が増える

MiroのStarterとBusinessは、メンバー1人ごとに料金がかかります。費用を抑えられるかどうかは、編集する人1人あたりの単価と、閲覧だけの参加者に有料の席が要るかどうかにかかっています。

FigJamは編集用のコラボシートがMiroのStarterより安く、閲覧とコメントだけの参加者に有料の席は要りません。Microsoft 365をすでに契約している会社なら、Microsoft Whiteboardは追加の費用なしで使えます。Whimsicalも閲覧者は無料ですが、編集する人の単価はMiroのStarterより高いため、費用を下げる目的では候補になりません。

  • この理由なら候補は FigJam・Microsoft Whiteboard（Microsoft 365を契約済みの場合）

日本語の窓口や請求書払いを重視したい

Miroは画面を日本語に切り替えられ、日本語のヘルプセンターもあります。有料プランの契約者は日本語で問い合わせできますが、日本語で返信されるかは公式に明記されていません。請求書払いは年払いで、Starterは10席以上、Businessは5席以上が条件です。日本からの新規契約で選べるかは明記されていません。

代替候補にも、日本語での有人対応を明記しているツールは見当たりません。請求書払いも上位プランが前提で、Whimsicalはエディタが10人を超えるBusiness、Muralは一部のBusinessプランで対応します。数人規模の契約なら、どのツールもカード払いになると考えておきましょう。

  • この理由なら、乗り換えても状況は大きく変わらない。まずMiroに問い合わせて条件を確かめる

会社の標準ツールに揃えたい

Microsoft 365・Teams、Zoom、Figma、Canvaのどれかを社内ですでに契約しているなら、追加の契約なしで試せるホワイトボードが手元にあります。ホワイトボードのためだけの契約と請求を、1つ減らせます。

  • この理由なら候補は Microsoft Whiteboard・Zoom Whiteboard・FigJam・Canva

無料版の制限と課金の単位をMiroと比べる

「編集できるボードは3つまで」という制限は、Miroだけのものではありません。無料のままボードを増やしたいなら、制限のかけ方そのものが違うツールを選びます。

無料版で作れる・編集できる範囲

  • Miro：編集できるボードは3件
  • Mural：ボードは無制限に作れるが、編集できるのは直近に作った3つ
  • Lucidspark：編集できるボードは3つまで（ボード内の図形数は無制限）
  • Zoom Whiteboard：無料アカウントに付くWhiteboard Basicで、編集できるボードは3つまで
  • FigJam：無料のスタータープランで、FigJamファイルは3つまで
  • Whimsical：ボード数は無制限だが、作れるオブジェクトは月50個まで。書き出しには透かしが入る
  • Canva：無料プランでもホワイトボードを必要な数だけ作れる
  • Microsoft Whiteboard：無料のMicrosoftアカウントで使え、単体の有料プランがない

8つのうち5つが「3」で並びます。無料プランでボードの数に上限がないと明記しているのはCanvaです。Whimsicalもボード数は無制限ですが、上限が月単位のオブジェクト数なので、毎週の定例で使うと、月の途中で上限に達することもあります。Microsoft Whiteboardをチームで使うなら、職場のMicrosoft 365アカウントで試してください。

有料プランの課金の単位と閲覧者の扱い

有料に切り替えたときの費用は、「誰に料金がかかるか」で変わります。各ツールの最安の有料プランは次のとおりです。

  • Miro：メンバー単位。Starterは年払いで月US$8（月払いはUS$10）
  • FigJam：コラボシート単位。Professionalのコラボシートは年払いで月US$3（月払いはUS$5）。日本向けの料金ページでは年払いで月450円。閲覧とコメントだけなら有料シート不要
  • Whimsical：エディタ単位。Proは年払い時月US$10。閲覧者は常に無料
  • Mural：メンバー単位。Team+は年払いで月US$9.99（月払いはUS$12）
  • Lucidspark：日本からは円建て・税別で表示。Individualは年払い時月1,300円、Teamは年払い時月1,500円／ユーザー
  • Zoom Whiteboard：ユーザー単位。Whiteboardプランは年払いで月US$5.83（月払いはUS$7.00）。Zoom Workplace Business以上にも無制限のホワイトボードが含まれる
  • Canva：1人あたりの年額。日本向けのProは個人向けで年11,800円、チームで管理するBusinessは年18,800円。ホワイトボード自体は無料プランで使える
  • Microsoft Whiteboard：単体の課金はなく、Microsoftアカウントや職場のMicrosoft 365の範囲で使う

1ドル=158円換算（執筆時点の目安。為替で変動）で、MiroのStarterは1人あたり月約1,264円、5人なら月約6,320円です。編集する人の単価で比べると、FigJamのコラボシートはMiroのStarterより安く、WhimsicalのProとMuralのTeam+は高くなります。日本向けに円建ての価格を出しているのはLucidspark・FigJam・Canvaで、ドルからの換算なしに予算を見積もれます。

日本語の画面で使えるMiroの代替ツール5選

ここからは、画面を日本語で使える5つです。前の章の無料枠や金額は繰り返さず、Miroとの違いに絞って紹介します。

FigJam：Figmaを使うデザインチームなら第一候補

Miroとの違いは、デザインツールのFigmaと同じアカウント・同じ料金体系の中にあることです。FigJamはFigmaの一部で、デザインファイルとホワイトボードを1つのワークスペースで行き来できます。

FigJamだけを使うなら、デザイン用のフルシートは要りません。コラボシートでFigJamをすべて使え、デザインファイルも閲覧とコメントまでは扱えます。無料プランでもAIクレジットが1日150、月に最大500まで付きます。

Miroからベクター形式で書き出したPDFは、Figmaのファイル画面から取り込めます。取り込んだ後は文字の編集や移動ができますが、コメントは移りません。

  • 向いている人：デザイナーとFigmaでやり取りしている企画・開発チーム

公式サイトで料金を見る →

FigJamの日本語ページでは、無料のスタータープランの範囲と、コラボシートで広がる機能を確認できます。

Canva：無料のままホワイトボードを増やしたい人向け

無料プランでもホワイトボードの数に上限がない点が、Miroとの一番の違いです。無料の範囲で、リアルタイムの共同編集、付箋の並べ替え、リアクション、音楽付きのタイマーまで使えます。

Canvaのアカウントを持っていない相手とも共同編集でき、書き終えたボードはプレゼンテーションやドキュメントに変換できます。会議で出たアイデアを、同じツールの中で提案資料に仕上げられるわけです。

ボードの数に上限はない一方、無料プランのクラウドストレージは5GBまでです。有料にする場合、支払いはJCBを含む主要カードとPayPalに対応しています。

  • 向いている人：無料のまま、プロジェクトごとにボードを分けて持ちたいチーム

公式サイトで料金を見る →

日本語の料金ページでは、無料プランとProの機能の違いを、円建ての年額と一緒に見比べられます。

Microsoft Whiteboard：Microsoft 365・Teamsの会社なら追加費用なしで試せる

単体の有料プランはなく、無料のMicrosoftアカウントか、職場・学校のMicrosoft 365アカウントでサインインして使います。ここがMiroとの大きな違いです。Microsoft 365をすでに契約している会社なら、ホワイトボードのために追加の請求は発生しません。これから契約する会社では、Microsoft 365そのもののライセンス費用がかかります。

Teamsの会議の中でそのまま開け、Web・Windows・iOS・Androidのどれからでも同じボードを共同編集できます。日本語のサポート記事も用意されています。

一方で、個人アカウントと職場アカウントでは使える機能に差があると公式に案内されています。個人アカウントで試した結果を、そのまま社内導入の判断に使うのは避けてください。

  • 向いている人：Microsoft 365とTeamsが社内の標準で、新しい契約を増やしたくない会社

公式サイトで料金を見る →

単体の料金プランはないため、日本語ページでは対応する端末とTeamsでの使い方を中心に確認できます。

Zoom Whiteboard：Zoom会議を中心に打ち合わせる人向け

Zoomの会議の中から、そのままホワイトボードを共有できます。別のツールのリンクを参加者に配る手間はかかりません。

ボードを無制限に使うには、Whiteboardプランを追加するか、ホワイトボードが含まれるZoom Workplace Business以上に切り替えます。会社ですでにBusiness以上を契約していれば、追加費用なしでMiroの代わりになる可能性があります。画面は、アプリとウェブサイトの表示言語を日本語に変えれば日本語で使えます。

  • 向いている人：打ち合わせをZoomで行い、会議中に図を描いて整理したいチーム

公式サイトで料金を見る →

公式ページは英語ですが、Whiteboard Basicでできることと、無制限に使えるプランへの切り替え先を確認できます。

Lucidspark：日本語の画面で図解まで一緒に進めたい人向け

図解ツールのLucidchartと同じLucidアカウントで使えるのが、Miroとの違いです。ホワイトボードで出したアイデアを業務フロー図などに落とし込むチームに合い、Enterpriseプランでは両方が一体で提供されます。

Miroからの移行手段が多いのも特徴です。コピー＆ペースト、ベクター形式のPDF、CSVの3通りでボードを移せ、どれも無料版から使えます。日本から料金ページを開くと円建て・税別で表示されるので、予算を見積もりやすい点も選ぶ理由になります。表示言語は日本語を含む12言語から選べ、日本語フォント「Lucid JP」もあります。

投票・タイマー・ファシリテーター機能はTeamプランにありますが、MiroもStarterでタイマーと投票を使えるため、ここは決め手になりません。無料版で編集できるボードもMiroと同じ3つです。有料プランには7日間の無料トライアルがあります。日本語の有人サポートがあるかは明記されていません。

  • 向いている人：Miroのボードを持ち込み、業務フロー図などの図解まで1つのアカウントで進めたいチーム

公式サイトで料金を見る →

料金ページを日本から開くと、各プランが円建て・税別で表示され、トライアルの条件もあわせて確認できます。

英語の画面でもよければ候補になる代替ツール2選

MuralとWhimsicalは、公式サイトが英語で、画面の日本語化も案内されていません。英語のままでも困らないチームなら候補に入る2つです。

Mural：ワークショップや研修の進行を重視するチーム向け

Muralは無料版の考え方がMiroに近く、ボード（Muralでは「ミューラル」）は無制限に作れますが、編集できるのは直近に作った3つまでです。有料のTeam+も年払いで月US$9.99とMiroのStarterより高いため、無料枠や費用を理由に移る先にはなりません。

選ぶ理由になるのは、ワークショップの設計手法までチームで取り入れたい場合です。BusinessプランではLUMAフレームワークを使ってワークショップを組み立てられ、Team+でもプライベートルームやMural AIが使えます。

支払いが止まったときの扱いは、Miroと異なります。ワークスペースごと停止し、ミューラルは削除されないものの、再開するまで開けません。Miroのように閲覧専用で残るわけではないので、止める前に書き出しを済ませておく必要があります。支払いはクレジットカードで、JCBが使えるかは記載がありません。

  • 向いている人：研修やワークショップの設計手法をチームで取り入れたい組織
  • 注意点：画面の日本語化は案内されておらず、サポートも英語が前提

公式サイトで料金を見る →

公式サイトは英語です。料金ページで、FreeとTeam+、Businessの機能の違いを確認できます。

Whimsical：図解とドキュメントを1か所で扱いたい少人数チーム向け

Whimsicalは、無料版の制限のかけ方がMiroと違います。ボードの数は無制限ですが、作れるオブジェクトは月50個までで、書き出しには透かしが入ります。ボードは分けたいけれど中身はシンプルな図で足りるなら、無料でも使える範囲はあります。

ホワイトボードとドキュメントを同じワークスペースで扱えるため、図解と説明文を別のツールに分けずに済みます。閲覧者は常に無料ですが、有料のProはエディタ1人あたりの単価がMiroのStarterより高くなります。年払いを選ぶと、月払いより17%安くなります。

  • 向いている人：ボードの数は多いが中身は簡単な図で足りる、少人数の企画・開発チーム
  • 注意点：画面の日本語化や日本語サポートは案内されていない

英語の料金ページで、Free・Pro・Businessの上限の違いと、エディタ1人あたりの金額を見比べられます。

乗り換えずにMiroを使い続けたほうがよいケース

7つを見比べても決め手がなければ、Miroに残る判断も十分にありえます。主要な代替ツールの多くは、無料版の上限がMiroと同じ「3つ」前後だからです。

無料版・Starterにかかわらず、Miroに残ったほうがよいのは次の条件に当てはまるときです。

  • 継続して編集するボードが3件以内に収まる
  • 日本語の画面のまま、タイマーや投票を使うワークショップを続けたい（Starter以上）
  • 既存のボードやテンプレートを作り直す時間を取れない

編集するボードが少ないなら無料版のままでよい

継続して編集するボードが3件以内なら、Miroの無料版で足ります。Mural・Lucidspark・Zoom Whiteboardに移っても無料版の条件はほぼ同じで、慣れた操作と既存のボードを手放す損のほうが大きくなります。

ボードを増やしたいチームはStarterを検討する

ボードの数が足りないことがはっきりしているなら、Starterに上げる手もあります。Starterでは非公開のボードを無制限に作れ、Visitorにも編集を許可でき、ボードを高解像度で書き出せます。タイマーや投票もStarterから使えます。乗り換えにかかる作り直しと周知の手間を、Starterの月額と比べて決めてください。

Miroから乗り換える手順（試用・ボードの書き出し・解約）

乗り換えは、候補を無料版で試してからMiroを解約する順番で進めます。請求期間が終わるとボードは閲覧専用になり、有料プランでしか使えない書き出しもできなくなるからです。

  1. 候補のツールを無料版で試す
  2. Miroのボードを書き出して手元に残す
  3. メンバーに移行先と切り替えの日を共有する
  4. Miroの有料プランを解約する
  5. 閲覧専用で残るボードの扱いを決める

乗り換え先を無料版で試してから決める

候補が決まったら、実際に使っているボードを1枚、候補のツールで作り直してみます。いつもの会議と同じ量の付箋や図を置けば、無料版の上限に届くかを具体的に判断できます。

Lucidsparkの有料トライアルは登録時に支払い情報を入力し、終了後は解約しない限り自動で課金されます。試すだけのときは終了日を控えておきましょう。

Miroのボードを書き出して手元に残す

解約する前に、残しておきたいボードを書き出して保存します。ボード左上のメニューから、画像（JPG・SVG）とPDF、付箋やカードの文字を並べたCSVを選べます。CSVは全プランで使えますが、ボードの構造は残りません。無料版で書き出せる画像やPDFは低解像度に限られ、ボードの所有者が書き出しを制限している場合は書き出せません。

FigJamとLucidsparkは、Miroからベクター形式で書き出したPDFを取り込めます。ベクター形式の書き出しはMiroの有料プランでしか使えないため、解約前に済ませておきましょう。

請求書と領収書も、BillingのInvoicesからこのタイミングでダウンロードしておきます。

解約しても既存のボードは閲覧専用で残る

Miroの有料プランは、管理者がBillingの画面から解約します。解約後も請求期間の終わりまでは有料機能を使え、未使用期間の返金はありません。残りの期間を移行作業にあてれば、支払った分を無駄にせずに済みます。

期間が終わってもボードは削除されず、閲覧専用で残ります。書き出し漏れがあっても中身は確認できますが、編集はできません。

まとめ：まず無料版で試し、理由に合う1つに絞る

Miroの代わりは、離れたい理由で決まります。

  • 無料のままボードを増やしたいなら、Canva
  • 編集する人の費用を抑えたい、またはFigmaを使っているなら、FigJam
  • Microsoft 365・Teams、またはZoom Workplace Business以上を契約済みなら、Microsoft WhiteboardかZoom Whiteboard
  • Miroのボードを移して図解まで進めたいなら、Lucidspark
  • 日本語の窓口が理由なら、乗り換える前にMiroに条件を問い合わせる
  • どれも決め手に欠けるなら、Miroの無料版かStarterに残る

候補を1つに絞ったら、いつものボードを1枚、その無料版で作り直すところから始めてください。
