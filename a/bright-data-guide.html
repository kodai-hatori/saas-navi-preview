Bright Dataとは？機能・料金・使い方と日本から契約するときの注意点を解説

開発・インフラ・データ 6,826字
#BrightData #Webデータ収集 #プロキシ #海外SaaS

スクレイピングの接続元を分散したい。ブロックへの対応を外部に任せたい。検索結果をAPIで取得したい。こうした要望を一つのサービス名で調べ始めると、Bright Dataの製品数と料金単位の多さに戸惑います。

Bright Dataは、プロキシだけを販売するサービスではありません。公開Webデータへアクセス・取得するためのプロキシ、Web Unlocker、Browser API（旧称・Scraping Browser）、SERP APIなどを提供する基盤です。何を取得するか、自社でどこまで実装するか、どの単位で費用を管理するかを決めると、選ぶ製品が見えてきます。

当メディアの運営者はBright Dataを契約・利用しています。この記事では実測値や成果を示さず、公式情報に基づいて選定に必要な情報を整理します。

結論：Bright Dataは複数のWebデータ取得手段を一つの基盤で選びたい事業者向け

Bright Dataが向くのは、プロキシ、ブロック対応、ブラウザ実行、検索結果取得を用途に応じて選び、Webデータ取得の仕組みを継続運用したい事業者です。 日本語の公式サイトと料金ページはありますが、管理画面の日本語対応範囲と日本語による有人サポートは明示されていません。一部の利用方法ではKYCも必要です。

公式サイトで料金を見る →

製品ごとに課金軸、無料枠、利用条件が異なります。最初に全体像を確認し、必要な製品だけを候補に残してください。

Bright Dataが向いている人

  • 複数の公開サイトから継続的にデータを取得したい事業者
  • 接続元の管理は自社で行い、Residential、Datacenter、ISPの各プロキシを用途で使い分けたい開発チーム
  • ブロック対応やブラウザ実行をサービス側に任せる選択肢も持ちたい人
  • 検索結果の取得に特化したAPIを探している人

別サービスも比較したい人

少量から単純な料金体系で試したい場合は、代替サービスも比較対象です。管理画面の日本語対応範囲が分からないことや、KYCが必要になることを負担に感じる場合も同様です。用途がプロキシだけなら、最低利用額や契約単位を優先して比べます。

Bright Dataとは？プロキシだけではない製品の全体像

Bright Dataとは、公開Webデータへの接続と取得を複数の方法で提供するサービスです。「BrightData」というスペースなし表記や「ブライトデータ」というカタカナ表記も同じサービスを指します。

公式サイトで料金を見る →

料金ページでは、製品ごとに異なる課金単位とプランを確認できます。

IP接続を自分で制御するプロキシネットワーク

Residential Proxies、Datacenter Proxies、ISP Proxiesは、自社の取得処理をプロキシ経由で接続したい場合の選択肢です。製品によってGB課金とIP課金があり、同じ「プロキシ」でも予算の立て方が違います。

取得処理は利用者側で用意し、Bright Dataから接続経路となるIPを調達する構成です。

ブロック回避やブラウザ実行を任せるWeb Unlocker・Scraping Browser

Web Unlockerはリクエスト数、Browser APIは転送量のGBを基準に費用を見ます。HTTPリクエストを中心に処理するのか、ブラウザ実行が必要なのかによって、選ぶ製品が変わります。

Web UnlockerはHTTPリクエスト、Browser APIはブラウザ実行を伴う取得を担います。

検索結果の取得を用途化したSERP API

SERP APIは検索結果の取得に用途を絞った製品です。費用はリクエスト数を基準に計算します。

Bright Dataでできることと製品の選び方

候補は「取得対象」「自社で持つ処理」「課金単位」の順に絞ります。以下のうち、自社の要件に最も近い入口から検討してください。

接続先やIPを細かく管理したいならプロキシ

取得処理を自社で用意し、接続経路を制御するならプロキシネットワークが候補です。転送量とIP数のどちらが費用を左右するかを見積もります。

ブロック対応まで任せたいならWeb Unlocker・Scraping Browser

ブロック対応を任せるHTTPリクエストならWeb Unlocker、ブラウザ実行まで必要ならBrowser APIが候補です。

検索結果を取得したいならSERP API

検索結果だけが必要ならSERP APIを選び、検索語数と取得頻度からリクエスト数を見積もります。

料金と無料枠は製品ごとに課金軸が違う

全製品を同じ条件で使える月額固定の無料プランはありません。対象APIとBrowser APIで共有する月5,000クレジットと、プロキシ向けの一回限りのトライアルクレジットは別の仕組みです。

  • プロキシ：ResidentialはPay as you goが$8/GB。DatacenterにはGB課金とIP単位の月額プランがあり、ISPにもGB課金とIP課金があります。
  • Web Unlocker／SERP API：通常のPay as you goはそれぞれ$1.5/1,000リクエストです。無料利用分は対象製品で共有するクレジットから消費します。
  • Browser API：Pay as you goは$8/GBで、月額固定のScaleプランもあります。無料利用分は同じ共通クレジットの対象です。

取得量を課金単位に当てはめて見積もります。期間限定の割引表示と通常単価は、混同しないように分けて確認してください。

公式サイトで料金を見る →

共通クレジットの消費量と、有料利用へ移った後の課金単位は製品ごとに異なります。使う製品を決めてから、該当する料金ページを確認してください。

プロキシはGB課金とIP課金を用途で選ぶ

ResidentialはGB単位の従量課金と月額プラン、DatacenterとISPはGB単位に加えてIP単位のプランもあります。転送量と確保するIP数のどちらが予算を左右するかを確認します。

Web UnlockerとSERP APIはリクエスト数で考える

Web UnlockerとSERP APIの有料利用は1,000リクエスト単位です。無料クレジットでは、どちらも1リクエストにつき1クレジットを消費します。

無料で試せる対象とクレジットカード要否を確認する

新規アカウントには、クレジットカード登録不要で月5,000の無料クレジットが付与されます。Web UnlockerとSERP APIでは1リクエストにつき1クレジット、Browser APIでは1MBにつき5クレジットを消費するため、全量をBrowser APIで使うと約1GB相当です。この5,000クレジットは、一つのアカウントで対象製品の利用分を共有します。

Residential、Datacenter、ISPの各プロキシは月額無料クレジットの対象外です。別枠で、新規登録時に一回限り$2のトライアルクレジットが付きます。クレジットの有効期間は7日間です。支払い方法を追加すると$5のボーナスが付き、30日間利用できます。

メリット・注意点・公開レビューから分かること

評価するときは、Bright Dataの製品の多さに加えて、料金管理、日本語UIの対応範囲、KYC、返金条件まで判断材料に含める必要があります。

メリットとして挙げられるのは、次の3点です。

  • プロキシ、Web Unlocker、Browser API、SERP APIを同じブランド内で検討できる
  • 自社で制御する範囲とサービス側へ任せる範囲を分けられる
  • 従量課金から始められる製品と、クレジットカード不要の無料枠がある製品を選べる

一方、契約前に押さえたい注意点は4つあります。

  • 製品ごとにGB、IP、リクエスト数と課金軸が変わる
  • 日本語の公式サイトと料金ページはあるが、管理画面の日本語対応範囲は公開情報だけでは判断できない
  • Residential Proxiesなど一部製品ではKYCが必要になる
  • サブスクリプション料金は解約しても返金されない条件がある

複数の取得手段を用途に合わせて選べる

接続経路を自社で制御する方法と、取得処理をサービス側へ任せる方法の両方を検討できます。検索結果だけが必要なら、SERP APIに絞れます。

料金管理と初期設定には学習コストがかかる

月額だけでは費用を判断できません。転送量、IP数、リクエスト数のどれが増えるかを見積もり、選んだ製品の設定項目を把握する手間も含めて検討します。

KYC・利用規約・返金条件を契約前に確認する

通常のResidential ProxiesでKYCを申請する場合は、登録企業と企業ドメインのメールが対象となり、利用目的の確認を受けます。身分証明書の提出やビデオ通話は追加で求められる場合があり、申請後48時間以内にステータスが更新されます。一方、robots.txtに従うImmediate Residential AccessはKYCなしで利用できます。固定期間の定めがない契約は、事前の書面通知を相手方が受領した暦月の末日で終了しますが、サブスクリプション料金は返金されません。

Webデータを取得するときは、対象サイトの利用規約、適用法令、Bright Data側の用途審査をそれぞれ確認してください。「合法」「安全」と一律には判断できません。

公開レビューは利用者属性と投稿経路を見て読む

ITreviewでは、小規模企業で有償利用するIT管理者が、プロキシを使った定期収集について、管理画面内の案内が製品選びや初期設定の助けになった一方、細かな設定はチャットやドキュメントだけでは分かりにくいと述べています。別の小規模企業による有償利用の投稿では、SERP APIをクライアント向けシステムへ組み込みやすかった点と、日本向けのWebサイトや製品マニュアルのローカライズ不足が挙げられています。

ITreviewでBright Dataの公開レビューを見る →

投稿には販売関係者によるものも含まれます。すべての利用者に共通する評価とは捉えず、利用製品、契約規模、投稿者の立場が自社に近いレビューを判断材料にしてください。

日本語対応と日本からの契約・支払い

日本語の公式サイトがあっても、契約と運用のすべてを日本語だけで完結できるとは限りません。サイト、管理画面、有人サポート、決済を分けて確認する必要があります。

日本語サイトと料金ページはあるが、管理画面の日本語UIは未確認

brightdata.jpでは製品紹介やサポート案内に加え、日本語の料金ページでUSD単価を確認できます。製品名やUSDの単位には英語表記が残るものの、料金ページの説明は日本語で読めます。

管理画面全体の日本語UI対応範囲は公開情報だけでは判断できません。日本語UIが必須なら、契約前に実際の画面で必要な設定項目を確認する必要があります。

日本語サポートの個別明記は確認できない

日本企業向けページには、主要言語での24時間サポートが案内されています。ただし、日本語チャットや日本語メール対応の個別明記は確認できません。標準サポートは営業日ベースのメール、PremiumとEnterpriseは24時間対応です。Enterpriseには専用Slackチャンネルがあります。

日本語の有人対応が必須なら、契約前に対応言語と窓口を確認してください。

日本からの支払い方法と請求書の条件

支払いはクレジットカード、PayPal、Alipay、Payoneer、Google Pay、Apple Payに対応しています。大口アカウントではWire transferも選べます。ただし、具体的な最低金額は示されていません。Wire transferは、日本企業が想定する請求書払いと同じ仕組みとは限りません。カードブランド別の対応可否も記載がないため、JCBが使えるとは断定できません。

領収書のダウンロード可否や日本の適格請求書に必要な登録番号の記載も確認できていません。税務上の処理が必要な場合は、契約内容と証憑をそろえて税理士に確認してください。

公式サイトで料金を見る →

使いたいカードブランドや日本語の有人対応が必須なら、申し込む前に個別条件まで確認してください。

Bright Dataの始め方：製品選択から小さなテストまで

製品を決めたら、アカウント作成後の設定、必要に応じたKYC、動作確認の順に進みます。

公式サイトで料金を見る →

対象製品が決まっていれば、登録後にプロキシ、API、ブラウザ系のどこから設定すべきか迷わずに済みます。

用途と製品を先に決める

登録前に選んだ製品名と課金軸を控え、アカウント作成後はその製品のセットアップへ進みます。その際、無料クレジットの対象か、プロキシ向けトライアルの対象かも確認します。

ZoneまたはAPI tokenを設定する

Web Unlocker、SERP API、Browser APIではzoneを作成し、API呼び出しではBearer API keyを使います。認証情報を発行したら、本番の取得処理へ組み込む前に、テスト用として分けて管理します。

KYCが必要な場合は対応し、小さなテストから始める

KYCを求められた場合は、登録企業の情報、企業ドメインのメール、利用目的を提出し、追加確認として身分証明書やビデオ通話を求められる可能性があります。Web Unlocker、SERP API、Browser APIは月5,000の共通クレジットから、プロキシは一回限りのトライアルクレジットから、少量で動作を確かめます。

Bright Dataが合わない場合の代替候補

法人向けの月額段階プランと試用条件を比べるならOxylabs、少量の月額契約や従量課金を優先するならDecodoが候補です。両者では、向いている契約のしかたが異なります。

Oxylabs：月額プランと法人向けサポートを比較したい場合

Oxylabsでは、Residential、ISP、Datacenter、Mobileの月額段階プランが基本です。ResidentialのStarterは5GBで月$30からです。Bright DataのResidentialが月額コミットメントなしの$8/GBから始められるのに対し、Oxylabsは月額の最小契約量を先に確保する形です。

常設の無料プランはありません。企業登録を確認できる法人には7日間、個人には3日間の返金保証があり、試せるのは1アカウントにつき1回です。日本語UIと日本語サポートは確認できません。

Decodo：小容量や従量課金から検討したい場合

DecodoのResidentialは、月額3GBで$11.25+VATから始められ、Pay As You Goは1GB単位で$4/GBです。月額の最小容量と従量課金の単位が小さい点は、Bright DataやOxylabsと比べるポイントです。Residentialには3日間・100MBの無料トライアルがありますが、終了後は有料プランへ自動移行し、通常プランの14日間返金保証は適用されません。

少量の月額プランや1GB単位の購入を優先するなら、比較候補に入ります。一方、公式サイトの日本語切り替えと日本語サポートの明記は確認できません。

まとめ：用途・課金軸・契約条件を決めてから選ぶ

契約前には、Bright Dataについて次の5点だけを最終確認します。

  • 取得対象：一般の公開ページか、検索結果か
  • 実装範囲：接続を自社で制御するか、取得処理を任せるか
  • 課金軸：GB、IP、リクエスト数のどれで予算を管理するか
  • 日本語：日本語の料金ページで足りるか、管理画面の日本語対応範囲を事前に確かめる必要があるか
  • 契約条件：自社の利用方法でKYCが必要か、返金されない料金条件を受け入れられるか

契約前の最終チェック

日本語対応、支払い方法、KYC、返金条件が自社の条件に合い、選んだ課金軸で利用量を見積もれるなら、Bright Dataは候補になります。いずれかが合わなければ、OxylabsやDecodoを同じ用途と契約単位で比べてください。
